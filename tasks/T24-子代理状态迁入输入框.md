# 子代理状态迁入输入框（流内条下线）方案

> 状态：定稿（2026-09-10）
> 级别：中（跨 composer / workspace 视图 / 折叠层 / demo 夹具；无外部契约变更）
> 用户裁决：① 删除流内「启动了 N 个子代理」条；② 状态改到输入框底行、权限选择框右边；③ 形态 = 一个图标按钮 + 小数字（工作中数量），0 不展示；④ 点击行为与旧条「打开 Agents」一致（打开侧栏面板）。

## 契约

- **无 hub 协议 / contracts API 变更**（纯渲染层）。
- 渲染层接口变更（内部面）：
  - `LiveWorkspaceView` 新增 `agentsWorking: number`（= `summarizeAgents(activeThread.agents).workingCount`）；`agentsActive` 语义不变（`agentsWorking > 0`）。
  - `Composer` 新增 `agentsWorking: number`、`onOpenAgents: () => void`。
  - `ComposerActionsRow` 新增可选 `agents?: { working: number; onOpen: () => void }`——不传即不渲染（新任务页无会话面，沿用「不摆假控件」约定）。
  - 新组件 `composer/agent-status-button.tsx`：`{ count: number; onOpen: () => void }`，`count <= 0` 返回 null。
- **TurnModel 契约收紧**：删除 `TurnBlock` 的 `subagents` 变体；`SubagentModel` / Agents 面板 / 折叠层 `state.agents` 不变（面板数据源本来就是 `state.agents`）。
- strings：新增 `flow.agentsWorking(count)`（按钮 aria/title）；删除仅流内条使用的 `flow.subagentsSummary`、`flow.notifySummary`、`flow.openAgents`。
- 副作用与事件时序：无新增事件；折叠层不再维护轮内块。

## 问题域

- 处理：
  - 输入框底行、权限模式菜单右侧新增「工作中子代理」图标按钮（`Bot` 图标 + 右上角小数字），`workingCount > 0` 才渲染；点击 = `openAgents()` 打开 Agents 侧栏。
  - 删除流内子代理条：`SubagentsBlock` 组件、`turn-block-view` 的渲染分支、`message-list`/`turn-group`/`thread-stage` 的 `onOpenAgents` 透传。
  - 删除被替换的折叠层实现：`syncSubagentsBlock` / `attachTailSubagents` / `SUBAGENTS_BLOCK_ID` 与 `fold-events` 各处调用；`turn-anchor-data` 的 subagent 摘要回退。
  - demo 夹具：`DemoBlockSpec` 的 `subagents` 块形态保留（脚本仍以块位描述子代理出场时序），派生层分流——`deriveLiveTurn` 返回 `{ turn, agents }`，agents 不再进轮内块、单独供给面板数据源，面板数据面不变。
- 不处理（归属）：
  - Agents 面板本体（列表/状态/steer/汇总）——保留不动。
  - 已确认的 6 个既有 bug（a 工具输出重复 / b startedAt 重置 / c 终态残留 running 工具 / d tokens·model·effort 未填充 / e 自动压缩失败无提示 / f 耗时 null）——各自独立方案，不在本批次。
  - 子代理明细完整性（relay 截断）——hub 侧既有取舍。
  - 历史轮锚点在没有正文/工具/失败时不再回退到子代理摘要（视觉回退项，随块下线一并移除）。

## 并发/一致性预算

- 无新增定时器、无新增 IO；徽标只读 `workingCount`（每渲染 O(agents)，单会话在飞 ≤8）。
- 折叠层净减少工作量：不再在每次子代理事件上重写轮内块（原 `syncSubagentsBlock` 每次 map 全部 blocks）。

## 实施顺序

1. **M1 徽标按钮 + 计数接线**：`LiveWorkspaceView.agentsWorking` → `Composer` → `ComposerActionsRow.agents` → 新组件；strings 增删。验收：组件测试（0 隐藏 / N 显示 / 点击回调 / aria 含数量）+ 四门。过渡态：流内条与新徽标并存（旧条下一步删）。
2. **M2 流内条下线 + 折叠层单轨**：删 `SubagentsBlock` 与渲染/透传；删 `subagents` TurnBlock 与折叠层同步逻辑；demo 夹具改轮次携带 agents；更新受影响测试。验收：全量 `bun test` 绿，且不存在 `subagents` 块残留引用。

## 裁决

- 默认裁决 A：图标 + 右上角小数字徽标（图标按钮惯例）；不用内联「图标+数字」胶囊。否决窗口：本方案随实现同批交付，可改。
- 默认裁决 B：`TurnBlock.subagents` 与折叠层同步逻辑一并删除（旧实现的唯一生产消费者是流内条；锚点回退与 demo 改用新载体），不留无人渲染的块。否决窗口同上。
- 引用既有裁决：新任务页不摆无数据面的控件（`ComposerActionsRow.session` 同款约定）。

## 测试口径

- 契约断言：`agentsWorking` 与 `agentsActive` 同源一致（working>0）；`ComposerActionsRow` 不传 `agents` 时无按钮。
- 边界：count=0 不渲染；count=1 显示 1；count>1 显示该数（静态 markup 断言，仓库组件测试口径；点击接线由 `IconButton.onClick` 承载，真机走查）。
- 折叠层：子代理事件只更新 `state.agents`（started/delta/text/tool/settled/message 六类），不再产生/迁移轮内块；停止与死亡仍就地终态（既有用例改断言后保留）。
- demo：live 轮在观察时刻产出的 agents 进入 `ThreadModel.agents`（面板数据面）。
- 回归：删除块后既有 agent 状态机用例全绿；`turn-anchor-data` 空摘要回退删除后仍不抛错。
- 分层：单元（新组件 + fold + anchor + demo）；无跨进程面 → 不加 e2e。
