# 侧边栏重构（分组/项目双视图 + 置顶） 方案

> 状态：已实施（对抗审查 + 多 agent 测试轮处置完毕，真机交互验证 + 视觉走查通过）
> 级别：中
> 参考稿：`sess_2c76fa3f…/image-6182…png`（分组视图）、`image-cb8e…png`（项目视图）——UI 按 1:1 还原

## 契约

- **零 hub 协议变更**：纯渲染层重构（数据全部来自既有 `SessionView` / `preferences`）
- 置顶复用 `preferences.pinnedSessions`（key = `sessionPath`，与设置页已保存列表同一真相；`null` sessionPath 的会话〔首条消息前〕不提供置顶入口）
- `SessionCardModel` 变更（渲染层内部模型，非协议）：
  - 删 `conversationId`（全仓零读取，只写不读的冗余字段）
  - 增 `sessionPath: string | null`（置顶键）
  - 增 `streaming: boolean`（行内活动指示数据源）
- strings 新 key（中英同步）：快捷区（新建任务/搜索/自动化/插件市场 + ⌘N/⌘K 徽标，修饰键符号按平台注入）、视图（分组/项目）、已置顶、置顶/取消置顶、显示更多、进行中、收起侧栏、相对时间标签（刚刚/N分钟/N小时/N天）；侧栏不再使用的旧 key 同步删除（allProjects/newProject/newThread）

## 问题域

- 处理：
  - 双视图数据编排：**分组视图**（置顶区 + 全量会话按 `lastActivityAt` 倒序平铺，每项相对时间标签）；**项目视图**（置顶区 + 按 `projectName` 分组，文件夹行可折叠、组内倒序、超限折叠 + 显示更多）
  - 置顶/取消置顶（hover 钉子，读写 `pinnedSessions`）
  - ⌘N 新建任务（NewThreadModal）、⌘K 搜索聚焦（内联搜索框展开 + 聚焦；已展开态再次触发重新聚焦）
  - 项目组折叠面：文件夹行单组折叠（折叠联动重置该组「显示更多」展开态）与「显示更多」展开
- 不处理（挂账）：
  - **底部功能按钮区保持现状不动**（用户裁决：settings/workflows/usage + refresh 不改；设计稿底部用户区〔头像/电话/齿轮〕不还原）
  - 工具栏 `#`（标签筛选）与垃圾桶（清理）图标——无标签/清理数据面，按仓库既有占位模式 noop，接线点保持稳定；本任务不做标签系统
  - 已保存未打开会话在侧栏展示（含置顶区）——置顶区只显示 live 会话；已关闭会话仍在设置页已保存分区（行为不变）

## 并发/一致性预算

- 相对时间标签沿用分钟级独立 tick（30s），不随流式 tick 重渲侧栏
- 折叠集合（项目组折叠、显示更多展开）为纯 UI 态，语言切换根级重挂载经 `uiState` 持久；视图切换（分组/项目）同 `uiState` 持久
- 置顶写路径复用 `updatePreferences` 串行链（既有），无新增并发面

## 裁决

- 默认视图 = 分组；两视图共用置顶区（置顶项不出现在下方列表）
- 显示更多：每组默认 5 条，展开后整组全量；折叠文件夹行联动清该组展开态（再展开回到 5 条截断）；不提供行内「收起」按钮（照稿单向）
- 底部功能按钮区不动（用户裁决）；工具栏三小图标：收起 = 折叠侧栏（两视图皆有效，与标题栏开合同一状态位，收起时联动收起搜索框），`#`/垃圾桶 = 纯视觉占位（aria-hidden 装饰钮，无数据面故不做可聚焦 noop 钮；接线时再替换为真控件）
- 搜索为行入口展开式（非常驻输入框）：点击「搜索」行或 ⌘K 展开内联输入框并聚焦（已展开时重新聚焦；收起态按 ⌘K 先展开侧栏）；Esc 收起并清空——Esc 分发链次序 = 对话框 → Usage → 新会话弹窗 → 设置 → **可见**侧栏搜索（侧栏收起时不参与链，过滤词保留、展开后恢复）→ 面板 → bash/停止；⌘N/⌘K 在任一模态覆盖/对话框开着时不劫持
- 项目分组键 = cwd（同名异目录不并组），显示名取 basename；组内与组间均按最近活跃倒序（输入顺序不构成前提）；显示更多 limit 钳制非负
- 侧栏默认宽度 264（可拖 208~400）；时间标签粒度：刚刚(<60s) / N分钟(<60m) / N小时(<24h) / N天(≥24h)，未来时间按刚刚；零会话（非过滤）显示 ⌘N 引导空态

## 测试口径

- `build-pinned-list`：交集/倒序/空 pinned/过滤查询联动/无 sessionPath 不入

- `build-project-groups`：分组键、组内倒序、组间按各组最近活跃倒序（输入乱序不构成前提）、limit 截断与 0/负数边界、expanded 全量、空组不出现、过滤联动
- `format-sidebar-age`：边界表驱动（0s/59s/60s/3599s/3600s/86399s/86400s/多天/未来）
- `group-collapse`：折叠联动清展开态（再展开回截断）、切回展开不动显示更多、expandGroup 幂等、输入集合不动
- `rename-commit`：trim 提交/空=取消/同名=取消（trim 后比较）/空原标题可命名
- `resolveCmdHotkey`：⌘/Ctrl 命中、无修饰与 Alt 不劫持、大小写形态
- `esc-action`：侧栏搜索收起优先级（对话框之后、面板/停止之前）
- 组件冒烟：Sidebar 双视图 `renderToStaticMarkup` 不抛错、关键节点在位（快捷区/徽标/Tab/置顶区/显示更多/空态/footer/流式指示）
