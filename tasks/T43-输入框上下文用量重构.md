## 0. 现状诊断（实测）

**展示面**：输入框用量芯片（`composer/composer-actions-row.tsx:115`）显示
`usage.stats.tokens.total`——数据源 hub `get_session_stats`，`total = Σ(input+output)`
**全程累计**：单调增、compact 后不重置、input 含 cache 读膨胀。这是 Codex 官方
issue #3630 记录的混淆形态原样复刻（「tokens are counted cumulatively while %
context can be reset」）。明细弹层（`usage-details.tsx`）同样只有累计口径：
input/output/total/cost/消息数/工具调用数——无窗口参照、无剩余/百分比、
无构成分项、无 cache 观测。

**行业对照**（2026-09 检索，Claude Code/Codex/ZCode 三家官方文档与 issue）：
- 主指标 = 上下文占用**百分比 + 绝对数并列**（Claude Code `215.2k/1m (22%)`），
  常驻输入区附近；
- 上下文占用分子 = **输入侧实报**（Claude Code used_percentage = input +
  cache_creation + cache_read，不含 output）；构成分项 = 估算（ZCode 官方声明
  「顶部真实用量/分项本地估算双口径不对齐」——双口径并存是常态）；
- 明细 = 按构成类别（system prompt / tools / messages / free space），
  桌面端点击弹层承载；
- 累计 token 与上下文占用**两个口径分开命名**（Codex #3630 混淆教训）；
- 变色阈值无官方内置值；Claude Code 官方示例脚本 绿<70 / 黄 70-89 / 红 90+；
- draft（未发送文本）计入估算：三家均无（负发现）——不发明。

**数据源**：hub 新命令 `get_token_analytics` 已在 x-harness 落地（默认装载、
`capability_plugin` 错误族、`lastReportedInput` = LLM 实报输入侧占用、
`breakdown.total` = 分项和（活线程下 ≈ lastReportedInput）、`contextWindow` =
装配窗口（与 compaction 阈值同源））。app 侧镜像未同步：hub 命令 60→61、
错误码表 + `capability_plugin`、`TokenAnalyticsData` 形状。

### 1.2 api 方法（M1）

```ts
// packages/contracts/src/api.ts
'session/tokenAnalytics': { params: threadOnly, result: TokenAnalyticsViewSchema }
```

`TokenAnalyticsView`（视图层收窄，展示就绪）：

```ts
{
  used: number;            // = breakdown.total（活线程≈lastReportedInput 实报；resume 无实报时=sys+tools 估算下限）
  window: number;          // = contextWindow（与 compaction 装备同源）
  utilizationPct: number;  // Math.round(total/window*100) —— 芯片主指标
  remaining: number;
  systemPrompt: number; tools: number; messages: number;  // 构成分项（估算口径）
  cacheHitRate: number; totalCacheRead: number; totalCacheWrite: number;
  sessionOutput: number;
}
```

- `packages/api/src/commands/session.ts`：`getTokenAnalytics`（default 超时档）；
- `packages/api/src/verbs/session.ts`：`'session/tokenAnalytics'` 路由 +
  `tokenAnalyticsView` 收窄器（views/response-views.ts）；
- `packages/api/src/client.ts`：session 域 `tokenAnalytics: call(t, 'session/tokenAnalytics')`。

### 1.3 渲染层展示（M3）

- **主芯片**（替换现累计 total 位）：`{utilizationPct}%` + tooltip
  `{used}/{window}`（formatTokenCount）；阈值变色：缺省 muted、`≥70%` warning、
  `≥90%` destructive（Claude Code 官方示例阈值）；
- **明细弹层**（usage-details 重构为双段）：
  - 上下文段：构成分项三行（system prompt / tools / messages，估算）+
    Free space（remaining）+ 窗口行；cache 行（命中率 %、累计读/写）；
    段首注明「分项为估算，与实报占用口径不同」（ZCode 双口径声明先例）；
  - 累计段：现有 SessionStatsView 六行原样保留（两口径分开命名）；
- **降级**：analytics 从未成功拉到（`capability_plugin`/旧 hub）→ 主芯片回落
  现有累计 total 展示（现状行为），弹层只渲染累计段——能力降级非兼容双轨
  （hub 命令面单一）；成功后失败保持 last-known（与 stats 同构，不闪跳）。
