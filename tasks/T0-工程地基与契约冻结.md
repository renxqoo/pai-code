## 契约

四件交付物：

1. **monorepo 骨架**：bun workspaces（`@paiapp/*`）；apps/electron（electron-vite 5 + Vite 7 三面 + TS7 + oxlint --type-aware + oxfmt + Tailwind4 显式 @source + shadcn 初始化）；packages/{contracts,core,infra,api,ui,testkit} 空实现 + `exports` 指向 `src/index.ts`（源码直出，无独立构建）。
2. **contracts 包**：UiEvent 全集（含 dialog_request 族）、InternalEvent（turn_started/turn_end/message_end{usage}/tool_call）、PaiCommand、ThreadRef/Route、Settings zod schema、`Client` 接口（invoke/subscribe/capabilities）、Port 接口（AgentHostPort/StorePort/SystemPort）、**hub 协议镜像类型**（帧与命令，从 hub 仓库 `src/protocol.ts` 抄录；同步纪律：hub 协议变更 → 本包同一提交内更新）。
3. **mock Client + 帧回放器**（packages/testkit）：内存实现 agentApi 语义 + `replay(frames)` 可调速派发，供 T8 波次 1 独立开发。
4. **lint 宪法 + pai 插件 + CI 四门**：`.oxlintrc.json`（jsPlugins 指向 `oxlint-plugins/pai/`，依赖矩阵与纪律规则 error 级零违规）；流水线 PR/夜间/发版三门骨架。

错误形态：契约包零运行时行为（纯类型 + zod）；lint 违规 → 退出码非 0（CI 红）。

## 裁决

- 引用总览「已裁决记录」（@paiapp、源码直出、TS7、依赖边界由 oxlint pai/* 插件强制）。
- hub 镜像类型用「抄录 + 同步评审」而非运行时依赖 hub 包：**默认裁决**（契约包保持零依赖、hub 工具链不入侵本仓库）；否决窗口至定稿。

## 测试口径

- 契约断言：词表双向封闭（UiEvent type / PaiCommand kind / 帧 type 与 hub design.md 逐项相等）；Client 接口形态穷举。
- 边界：zod 空 patch/未知键；回放器空夹具、晚订阅。
- 分层：仅单元；无 integration/e2e。
