## 契约

- **项目行「更多」菜单**（hover 出现菜单钮，锚定下拉）：①新建任务（NewThreadModal 预填该项目 cwd，复用既有 `defaultCwd` 仅打开瞬间重置语义）②移除项目 ③查看项目文件
- **移除项目 = 隐藏**（不删会话/不删文件）：`preferences` 增 `hiddenProjects: string[]`（键 = cwd，`Settings`/`updatePreferences` patch 白名单同步）；侧栏两视图（置顶/分组/项目组）过滤隐藏 cwd 的会话；**恢复通路**：在隐藏目录新建任务成功时自动解除隐藏（`createSession` 成功后从数组移除）
- **项目文件面板**（图3 **侧栏内嵌面板**：无遮罩、侧栏同宽、替换侧栏内容区，顶行返回箭头+项目名/路径、次行搜索框）：数据源复用 `'file/search'`（`query: ''` 空查询 = 全量清单 ≤200 条，主进程扫描 + 已知目录门禁，无新 IPC/协议命令）；新增渲染层 action `listProjectFiles(cwd)`（区别于既有面向活跃会话的 `searchFiles`）；展示模型由纯函数 `build-file-tree`（路径 → 树）产出；**面板内搜索 = 本地过滤**（`filter-file-tree`：子串命中保留祖先链、目录命中保留子树，无新请求）
- Esc 链插入：面板为侧栏内联层（对话框 → Usage → 新会话弹窗 → 设置 → **可见项目文件面板** → 可见侧栏搜索 → 面板 → bash/停止；面板可见性同搜索按侧栏未收起 gate）
- strings 新 key（中英）：移除项目 / 查看项目文件 / 项目文件空态 / 移除项目恢复提示（若图有）

## 问题域

- 处理：项目 cwd 维度的三个入口动作 + 文件树构建（纯函数）+ 隐藏项目过滤（三列表共用）
- 不处理（挂账）：
  - 面板内文件操作（打开/预览/在编辑器打开）——大逻辑第二阶段；文件清单为 ≤200 条截断视图（分页/全量树后续按需）
  - 隐藏项目的设置页管理分区（恢复通路首版走「同目录新建任务」）

## 裁决

- 移除项目 = 隐藏该项目全部会话（不 dispose、不动文件）；恢复 = 同目录新建任务自动解除（最小闭环，设置页管理挂账）
- 项目文件首版 = `file/search` 空查询全量（≤200 条、深度≤8、跳过 node_modules/.git 等既有预算）；树形展示模型（目录聚合节点 + 文件节点）；面板内搜索 = 本地过滤（不回主进程）
- 基于项目新建任务 = 打开既有 NewThreadModal 并预填 cwd（trusted 开关/已知目录 chips 全部沿用）
- 菜单用既有 `@paiapp/ui MenuButton`（锚定下拉形态与图一致）

## 测试口径

- `hidden-projects`：隐藏过滤（置顶/分组/项目组三面同源）、空集合同引用、恢复路径
- `build-file-tree`：嵌套路径聚合、目录先于文件、同名排序稳定性、空输入、深层截断数据
- `filter-file-tree`：空查询同引用、子串命中保留祖先链、目录命中保留子树、大小写不敏感、无命中空数组
- `settings/api` 契约：`hiddenProjects` 默认 []、patch 可选、未知键拒绝（沿用既有用例模式）
- `esc-action`：项目文件面板优先级位（全屏覆盖层后、侧栏内联层内先于搜索）
- 组件冒烟：菜单三项渲染（文案/图标）、面板树渲染与空态
