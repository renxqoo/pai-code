# Pai Code C 端企业级 UI/UX 重构

> 状态：已核销
> 级别：大
> 范围：`apps/mobile`

## 目标

在完整功能基础上，将移动端从“可用原型”提升为精美、克制、可信赖的 C 端企业级产品。设计延续参考图的轻量、舒展、连续列表语言，不复制具体品牌资产。

## 设计契约

- 对话、搜索、项目与资产使用纯白背景；设置类页面使用冷灰背景与白色分组。
- 无装饰性外描边；层级由圆角、柔和阴影、背景差和极浅分隔线表达。
- 顶栏与抽屉不重复提供搜索、设置等入口；高频操作始终可发现，低频操作进入菜单或分组。
- 空态必须提供至少一个可执行起点；选择器必须展示当前值、说明和选中反馈。
- 触控目标不小于 44pt，视觉图标可更小；文字缩放时关键操作不溢出。
- 所有用户路径提供返回、关闭或安全退出，不存在无结果按钮。

## 实施顺序

1. 统一设计 token、PageHeader、设置列表行与分组。
2. 重构对话顶栏、空态、消息、Composer 和所有 Sheet。
3. 收敛抽屉导航、历史与项目层级。
4. 统一设置主页及补充页面。
5. 补回归测试、覆盖率、lint/typecheck/build、双平台 bundle。
6. 使用 bw 在移动视口执行新任务、附件、模型、权限、上下文、历史、设置和返回旅程。

- [x] 核心 C 端旅程无死链、无遮挡、无横向溢出。
- [x] 设置分组具备清晰分隔，页面冷灰背景与内容白卡一致。
- [x] 首页、抽屉、Composer、任务配置和设置页达到统一视觉层级。
- [x] Composer 紧凑态为 58px，顺序为附件 / 输入 / 发送；聚焦态为 132px，顺序为输入区 / 附件 / 发送，底部保留 16px 安全间距。
- [x] 顶栏任务配置集中管理模型、思考、权限和上下文，输入区不再承载配置控件。
- [x] bw 移动视口 console/errors 为空；所有 44pt 操作可点击。
- [x] 根级四门、覆盖率与 iOS/Android bundle 全绿。
