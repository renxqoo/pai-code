# T9 · 测试装置与打包分发（CI 分层 / 混沌 / E2E / bun+hub 打包） 方案

> 状态：草稿（待评审定稿）｜ 级别：中 ｜ 波次：1（装置先行）/ 3（收口） ｜ 依赖：装置仅 T0；收口依赖全部 ｜ 被依赖：全部（门禁与 testkit）
> 方案依据：方案第 12、13 章

## 契约

```text
CI 三门（流水线即产物）：
  PR 门：四门 + 全部 __test__ + T1 夹具回归 + 覆盖率阈值（≥90/≥85）
  夜间门：integration（真 bun + 真 hub，opt-in LLM 门）/ 混沌
  发版门：E2E + 打包冒烟 + license 审计
testkit（唯一跨包测试资产）：fakeHub（T2 晋升，剧本化帧/挂死/崩溃/EOF/孙进程）
  + replayHarness + mock Client（T0 迁入）+ tmpWorld（隔离数据区 + 自清）
E2E 旅程：3 对话 × 2 thread 事件不串线；渲染层刷新重水化
发版产物：electron-builder 包 + extraResources（bun 二进制三平台锁定修订 + hub dist + 哈希清单）
  + mac 公证 + win codesign + 第三方许可列表（hub/pi MIT）+ 更新通道（HTTPS+签名校验+回滚目录）
```

- 旅程断言 = 业务终态（各 thread 消息归属/终态/usage 与种子对账），非「没崩」。

## 问题域

- 处理：CI 三门与门禁矩阵；testkit 三装置；integration 任务集（真 hub：thread 生命周期/prompt/steer/abort/resume/auth 命令组）；混沌（kill -9 hub、心跳停、坏帧流、stdin EOF 双向、hub 长跑内存阈值）；E2E；打包（bun/hub 产物与哈希、公证、codesign、license、EDR 清单）；更新通道与回滚；导出/诊断包打包侧。
- 不处理：各包单测（各自 __test__）；被测逻辑本身（装置挂了按定位纪律找归属，不越界代修）。

## 并发/一致性预算

- 混沌长跑：hub 8 thread × 1 小时，验收 = 应用整体 RSS < 物理内存 60%；装置纪律：无共享可变状态、数据自清、共享资源文件级串行；E2E 单旅程 ≤3 分钟；夜间门 ≤2 小时。

## 拆分


## 实施顺序（每步独立测试 + 四门全绿后提交）

| # | 内容 | 单测/验证 | 验收 |
| --- | --- | --- | --- |

| M2 | testkit 三装置 + fakeHub 晋升 | 装置自检：并行隔离/自清零残留/行为向量穷举 | T4/T6 可复用 |

## 裁决

- E2E 用 @playwright/test 自带 runner：既有裁决。
- 真凭证 LLM 门 opt-in 不进默认门禁：既有裁决。
- LLM 网络依赖的 integration 用例全部标注 opt-in：**默认裁决**，否决窗口至定稿。

## 测试口径

- 契约断言：三门触发矩阵表驱动；旅程与种子对账。
- 边界：装置故障（fakeHub 超时/平台缺失 bwrap → skip 且报告不静默绿）；覆盖率未达标保持红。
- 假绿对抗抽查（收口强制）：无新增 skip/被注释用例/被改断言；抽查记录落档。
- 分层：装置自检单测 → 夜间 → 发版；本任务的元测试 = 门禁真的在拦。
