## 修复：注册表 updatedAt ≡ 会话最后活动时间（点击会话不再置顶）

> 状态：已实施 ｜ 级别：中 ｜ 症状：侧栏点击 parked 会话 → 立即置顶 + 相对时间变「刚刚」，重启后仍置顶

### 根因

`SessionRow.updatedAt`（行更新时间）被同时当作 `SessionView.lastActivityAt`（会话活动时间）消费（对账占位、侧栏排序、相对时间标签），三个写入点把两者搅在一起：

1. `applyStartOutcome` 对 start/resume/fork 一律 `lastActivityAt: Date.now()`——恢复不是会话活动；
2. `persistSession` 无条件 `updatedAt: Date.now()`——改名等元数据写也推进活动时间；
3. 真活动（turnStarted/turnSettled）只更新内存视图不落库——重启后活动时间回退到上次 resume/start 时刻。

### 契约（语义收紧，形状不变）

- `SessionRow.updatedAt` ≡ 会话最后活动时间（`SessionView.lastActivityAt` 的持久镜像）。只有会话活动推进：新建（start）/ fork / turn（agent_start/agent_settled）。选中、恢复、改名、元数据补全不推进。行内时间单调（`persistSession` 钳制 `max(行内值, 视图值)`，交错写入不得回退）。
- `PaiRuntime.applyStartOutcome` 新增必填 `lastActivityAt` 参数：活动语义由调用方裁决（start/fork = now；resume = 保留）。
- resume 活动时间取值链：`max(写时注册表行快照, 会话文件 mtime)`（帧同步派发先于 resume 续体，await 窗口内的 turn 推进不得被过期快照写回；mtime 亦覆盖强杀落盘未入表的尾巴）→ 双源皆不可得（无行且 stat 失败）降级当前时刻。

### 不处理

- 存量行已被历史 resume 推进过的 `updatedAt` 不回填（无真相源；只影响旧会话排序起点）。
- 换 id resume 时 `createdAt` 重置为当前时刻的既有行为（排序只看 updatedAt）。
- History 首开旧行时新行 `createdAt`(now) > `updatedAt`(mtime)：`createdAt` 当前无消费方（只写不读），待首个消费方落地时一并裁决。
- 内部重开链 `session/stop remove=false` 摘视图后迟到的 `agent_settled` 不落库：该轮起点已落库（turnStarted 先行持久化），误差上界 = 单轮时长。
- `findRegistryRowByPath` 精确字符串匹配（路径形态分歧 → 行 miss → 标题回退默认值）：既有行为，先于本修复存在。
- 渲染层零改动（排序/相对时间标签消费面已正确；点击 live 会话本就不推进）。

### 测试口径（症状回归）

- 点击不置顶：seeded updatedAt=2000 → resume → 内存视图与注册表行仍 2000。
- 改名不推进：rename 后 registry.updatedAt 不变。
- 真活动落库：turnStarted/turnSettled 后 registry.updatedAt 前进（内存与库一致）。
- start/fork 仍取当前时刻。
- History 首开（无行）：活动时间 = 会话文件 mtime；文件不可读 → 当前时刻。
- 重启不重排：resume 后对账占位 lastActivityAt = 保留值。
- 竞态（对抗审查 #1/#2）：resume 续体前真活动已推进（帧先于微任务）→ 活动时间不写回旧值、恢复后下一轮照常推进；换 id 且旧文件更旧 → 新行保留旧行值。

### 对抗审查处置（独立会话，7 项）

- #1 resume await 窗口竞态（帧同步派发先于续体，过期快照写回/整轮丢失）：**已修**——写时重读行快照 + `max(行, mtime)` + `persistSession` 单调钳制；带竞态形状回归。
- #2 注册表时间可倒退（无单调钳制）：**已修**——`Math.max(行内值, 视图值)`。
- #3 视图空窗期活动丢失：#1 修复覆盖竞态空窗；stop 摘视图后迟到 settle 的残余误差落「不处理」（上界 = 单轮时长）。
- #4 行快照信任过旧行 / 路径精确匹配：取值链改 max(行, mtime) 后行旧而文件新时取文件；路径匹配 miss 为既有行为，落「不处理」。
- #5 History 首开 createdAt > updatedAt：`createdAt` 无消费方，落「不处理」。
- #6 测试空转断言/缺口：收紧 `toBeGreaterThan`；补竞态形状、换 id 邮戳、恢复后下一轮推进用例。
- #7 存量脏值被保留路径延续：即「不回填」裁决本身，维持。

### 裁决（既有裁决的回归）

- T16 §23 已裁决「侧栏渲染只需注册表 title/updatedAt」——`updatedAt` 的预期语义就是活动时间，无条件 `Date.now()` 是对该裁决的偏离。
- 真活动（turn）落库：否则重启后排序回退到上次 resume 时刻，治标不治本。
- History 首开无行时取文件 mtime 而非当前时刻：打开三个月前的会话不应置顶。
