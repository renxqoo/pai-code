# Pai Code 对话时间线与 Mock 展示

> 状态：已核销
> 级别：中
> 范围：`apps/mobile`

## 目标

用完整但易读的 Mock Agent 对话验证消息、思考、工具调用、代码与运行状态在移动端的真实展示，并建立可复用的时间线分组规则。

## 外部契约

- `ChatMessage` 新增可选展示元数据：状态、耗时、行数和结果摘要；不改变消息正文与创建时间。
- 连续 thinking 合并为思考块，连续 tool 合并为执行块；用户、助手、系统和代码保持独立消息边界。
- 折叠状态仅是 UI 状态；不持久化、不影响消息顺序。运行中的工具组固定在输入框上方的执行清单，历史工具组保留在时间线。
- 空态提供进入示例会话的真实入口。

## 处理

- 完整 Mock 会话覆盖用户请求、思考、读取、搜索、编辑、工具成功、正文结论、代码变更、完成状态。
- 默认折叠长思考和连续工具；展开后显示每一步。
- 首次生成、工具执行、完成和失败提供不同 loading/status 行。
- 长代码默认截断，展开显示完整内容。
- 附件在用户消息内展示；权限继续使用独立确认卡。

## 不处理

- 不接真实流式事件、不解析 Markdown、不执行工具。
- 不新增持久化、网络层或业务异常。
- 不在移动端渲染桌面端完整 diff/终端 transcript。

## 测试

- 分组函数覆盖连续 thinking、连续 tool、混合边界和空输入。
- 折叠块可展开/收起并暴露正确 accessibility state；底部执行清单同样支持收起与展开。
- loading、工具运行、完成、失败状态分别有组件断言。
- 空态入口可打开完整 Mock 会话。
- 消息列表无横向溢出；移动端 bw 验证折叠、展开和状态行。

## 验收

- [x] Mock 时间线在移动视口可读，连续工具不刷屏。
- [x] 历史执行组保留在时间线，运行中执行组固定为可收起的底部 Todo 清单。
- [x] 状态文案不与正文混淆，展开后才出现细节。
- [x] 覆盖率、四门与双平台 bundle 全绿。

## 验证记录

- 移动端 Jest：18 suites / 73 tests 全绿。
- 移动端覆盖率：语句 95.22%、分支 89.37%、函数 93.98%、行 97.27%。
- Mock 包含 14 次工具调用、3 个连续执行组、失败后诊断重试和 Web/iOS/Android 验证。
- bw 移动视口：时间线、思考/工具折叠、代码截断、完成/失败状态、脱离文档流的绝对定位 Todo、动态滚动预留、紧凑输入区与 Todo 收起/展开均通过；浏览器 errors 为空且无横向溢出。
