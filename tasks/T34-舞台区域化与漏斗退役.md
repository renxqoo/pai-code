## 1. DESIGN

### 1.1 外部契约

**组件面（终态 props）**

| 组件 | props | 数据通路 |
| --- | --- | --- |
| `ThreadStage`（区域化，React.memo） | **0** | live：activeThread（items/agents）/sessions[tid]/dialogs/threads 状态派生/**hostPhase**（掉线横幅）；ui：sidebarCollapsed/bottomInset/panel；动作：workspaceActions + workspace-fork + panel 动作 + uiStore.openSettings；now tick 本地（见预算） |

**store 与单例面**

- ui store +`panel: PanelState`（当前多标签态；会话存档 `panelByThread` 仍模块级档案，非当前态）+`filePickerOpen/filePickerItems` +`composerInset: number`（输入浮层高度测量值）。动作：panel 纯函数包装（openDiff/openAgents/togglePanelFromHeader/toggleDiffPane/toggleAgentsPane/closePanel/closeTab/focusTab/openFileTab(cwd)）+ setFilePickerOpen + setComposerInset。`reset()` 收编。
- `panel/panel-controller.ts`（新）：`openFilePicker()`（开弹窗 + searchFilesIn 注入拉全量清单——先例 project-files 的注入缝，**含代次守卫**：快速重开丢迟到响应；失败 null 保持空清单降级）、`readFile(cwd,path)`（bridgeClient）。panel-state.ts 纯函数与测试不动。
- **panelByThread 存档/恢复触发器**：useWorkspaceRuntime 内 effect（keyed `[activeThreadId, panel]`，「panel 变化即存档」时机与原 hook 同构）。
- ui store `setComposerInset(rawHeight)` 接收**原始测量值**，+24 偏移在动作内完成——测量回调保持模块级稳定引用（顺修 inline 箭头致 observer 每渲染重挂的瑕疵）。
- `thread/use-elapsed-now.ts`（新共享 hook）：executing/agentsWorking 门控的 1Hz tick，ThreadStage 与 AgentPanel 各挂一份（本地态，不进 store——1Hz 重渲半径=所在区域）。
- **切会话 effect 整体同构迁入 useWorkspaceRuntime**（keyed `[activeThreadId, activeSessionState, activeSessionModel]`，五项一个不少：agentDefinitions 清空、controller.ensureHydrated（冷启动 parked 水化唯一通路）、controller.readSessionRules、parked 态 effortLevelsForModel 本地推导、live 态 thinkingLevels/commands 拉取——判活守卫原样）。

### 1.2 内部问题域

**处理**：舞台/面板/横幅区域自订阅；面板系统单例化；bottomInset 通道 store 化；now tick 本地化；七个冷路径消费面改直订阅；漏斗与 god-object 类型删除。

**明确不处理**：MessageList/ThreadHeader 等舞台内部子件 props 契约（区域内 props 合法）；settings 页内部结构（只换数据源不改装配逻辑）；palette open 态留 WorkspaceMain 本地（开合低频）；Esc/热键门控输入面（M3 后 dialogs 等仍由 WorkspaceMain 低频订阅喂入——热路径无订阅）。

### 1.3 并发与性能预算（违反 = 缺陷）

- **流式批推重渲半径 = 舞台内消息区**：WorkspaceMain 订阅面=终态清单（全低频），批推帧 WorkspaceMain 零重渲、PanelLayer 无关面板零重渲（B-batch 用例：M2 钉「舞台提交且 memo 不被击穿」、M3 钉「WorkspaceMain 探针零」）。
- 输入卡高度变化（composerInset 写 store）只重渲舞台订阅处，WorkspaceMain 零重渲。
- 全局 1Hz 定时器 ≤2（原 1：executing/agentsWorking 各门控一份；涨幅恒定记录在案）。
- ui store panel 动作零 IO；openFilePicker 搜索是面板域唯一 IO（注入缝）。
- runtime mount 的目录 effect 判活守卫原样（响应到达时会话已切换则丢弃）。

## 3. MIGRATION

### 3.1 行为规格基线

1. 贴底跟随/回底浮标（bottomInset 避让 +14px）；轮锚点跳转（尊重减弱动态）。
2. 头部菜单全链：重命名/复制 ID/受信重开×2/归档/关闭/项目三开（finder/terminal/editor）/复制路径。
3. 面板：头部开关（开=整组收起/关=Diff 打开）；多标签聚焦关闭；切会话组态存档恢复；⌘⇧D/⌘⇧A toggle。
4. 文件选择器：进入拉全量 + 客户端过滤；文件 tab 读取（readFile）。
5. 状态徽标：权限等待/压缩/生成/队列计数派生；掉线横幅进设置。
6. 横幅：crashed/compacting/retrying/queue/bash 尾部。
7. 消息流：loading 尾、空态/水化失败重试、编辑/分叉回调。
8. **批推重渲半径（新）**：流式批推只重渲舞台消息区；高度变化只重渲舞台。
9. 引导屏/启动守卫/用量页/命令面板/新建页行为不变（数据源换轨）。
10. ComposerRegion 归零 props（agents 入口走 controller）。

### §6.1 交付后实测修复（用户现场报告，2026-09-11）

- **「刷新页面当前会话变空态，重启服务才恢复」**——根因在 entry-hydration（T27 期代码，非本任务引入）：`ensureHydrated` 只对 parked 会话拉取历史，live 会话直接早退；渲染层重载后 store 全新而事件流不重放历史，活跃 live 会话（worker 未闲置回收）水化缺失 → 空态。重启服务 = hub 重启、会话全部回落 parked → register+entries 全量显示，故「又正常」。修复：非 parked（live/dead）同样全量拉补（零 register 零 resume，表项已在 hub）；红测→绿测回归 2 用例（症状命名）。
- **「输出时内容被输入卡遮挡」**——实测排除：避让通道健康（截屏实测执行行距输入卡顶 ≈ +24 呼吸位精确在位；测量→ui store→舞台 padding 链路与 main 逐字节同构）。最可能成因是 dev 态 HMR：流式期间仓库内渲染层源码变更被 Vite 热替换进运行中应用造成的瞬态（当时正在合入 §6 修复）。未复现不修；若在无并行改码时复现，按「DevTools 读 composerInset vs 浮层 rect 高度差」取证。

### §6.2 轮结算历史塌缩（用户现场二报，2026-09-11）

- **「对话结束滚动条没了、对话收起来了，刷新才恢复」**——截屏实锤：结算后整段历史消失、仅剩当轮。根因：`rebuildFromTranscript` 的**窗口载荷**（since=轮首游标，hub `get_entries` 只回本轮条目）被喂给**整表替换**的 `hydrate/rebuild` 折叠——「轮内窗口重建」优化落地时折叠未同步（设计意图「替换本轮 span」，实际整表塌缩）。两个调用方全中：轮结算（live-controller settle）与直执行 bash（runBash 的 cursorBefore 窗口）。修复：`rebuildFromTranscript` 按 since 分流——窗口载荷走 `hydrate/reconcile`+dropLiveTurn（保历史前缀、权威转写替换本轮 span、清 live 句柄）；仅全量拉取（since 空）保留整表 rebuild。回归：症状命名用例（历史保住 + 窗口权威呈现 + liveTurnId 清空）。
- 与 §6.1 的关系：塌缩把「重载后空态」放大成日常可见（每轮结算/每次直执行 bash 都触发）；「输出时遮挡」大概率同为塌缩的视觉伴生（列表骤缩骤涨 + live 句柄被清导致重复折叠），待用户在两修复上复验。
