## 1. DESIGN

### 1.1 外部契约

**组件面（终态 props）**

| 组件 | props | 数据通路 |
| --- | --- | --- |
| `ThreadStage`（区域化） | **0** | live：activeThread（items/agents）/sessions[tid]/dialogs/threads 状态派生；ui：sidebarCollapsed/bottomInset/panel；动作：workspaceActions + workspace-fork + panel 动作 + uiStore.openSettings；now tick 本地（见预算） |
| `PanelLayer`（区域化） | **0** | ui：panel/filePicker；live：activeThread.agents/threadDiff 派生；controller：readFile |
| `ThreadBanner` | **0**（自订阅活跃线程状态） | live：threads[tid] crashed/compacting/retrying/queue/bash |
| `ComposerRegion` | **0**（T33 的 onOpenAgents 挂账解除） | agents 入口改 panel-controller |
| `usePanelTabs` | **删除** | 状态进 ui store，动作进 controller |
| `useLiveWorkspace`/`LiveWorkspaceView` | **删除** | 全消费方直订阅；生命周期/目录拉取/冲刷连接归 `useWorkspaceRuntime()`（新，挂 workspace-screen：controller start/dispose + 会话目录 effect + queued-flush 连接，约 50 行单一职责） |
| settings/newTask/palette/bootstrap/usage/onboarding 装配面 | 输入面改 store 订阅 + 单例 | LiveWorkspaceView 类型退役，全仓 grep 零引用 |

**store 与单例面**

- ui store +`panel: PanelState`（当前多标签态；会话存档 `panelByThread` 仍模块级档案，非当前态）+`filePickerOpen/filePickerItems` +`composerInset: number`（输入浮层高度测量值）。动作：panel 纯函数包装（openDiff/openAgents/togglePanelFromHeader/toggleDiffPane/toggleAgentsPane/closePanel/closeTab/focusTab/openFileTab(cwd)）+ setFilePickerOpen + setComposerInset。`reset()` 收编。
- `panel/panel-controller.ts`（新）：`openFilePicker()`（开弹窗 + searchFilesIn 注入拉全量清单——先例 project-files 的注入缝）、`readFile(cwd,path)`（bridgeClient）。panel-state.ts 纯函数与测试不动。
- `hooks/use-observed-height` 测量写 store：workspace-main 的 composer 层测量 effect 改 `setComposerInset`（不再 setState——高度变化零 WorkspaceMain 重渲）。
- `thread/use-elapsed-now.ts`（新共享 hook）：executing/agentsWorking 门控的 1Hz tick，ThreadStage 与 AgentPanel 各挂一份（本地态，不进 store——1Hz 重渲半径=所在区域）。
- 会话目录拉取 effect（commands/effortLevels，现 useLiveWorkspace 内）**同构迁入 useWorkspaceRuntime**（keyed activeThreadId/activeSessionState/activeSessionModel，判活守卫原样）。

### 1.2 内部问题域

**处理**：舞台/面板/横幅区域自订阅；面板系统单例化；bottomInset 通道 store 化；now tick 本地化；七个冷路径消费面改直订阅；漏斗与 god-object 类型删除。

**明确不处理**：MessageList/ThreadHeader 等舞台内部子件 props 契约（区域内 props 合法）；settings 页内部结构（只换数据源不改装配逻辑）；palette open 态留 WorkspaceMain 本地（开合低频）；Esc/热键门控输入面（M3 后 dialogs 等仍由 WorkspaceMain 低频订阅喂入——热路径无订阅）。

### 1.3 并发与性能预算（违反 = 缺陷）

- **流式批推重渲半径 = 舞台内消息区**：WorkspaceMain 不再订阅 sessions/threads/stats——批推后 WorkspaceMain 探针零渲染、PanelLayer 无关面板零重渲（B-batch 回归双用例钉住）。
- 输入卡高度变化（composerInset 写 store）只重渲舞台订阅处，WorkspaceMain 零重渲。
- 全局 1Hz 定时器 ≤2（原 1：executing/agentsWorking 各门控一份；涨幅恒定记录在案）。
- ui store panel 动作零 IO；openFilePicker 搜索是面板域唯一 IO（注入缝）。
- runtime mount 的目录 effect 判活守卫原样（响应到达时会话已切换则丢弃）。

## 3. MIGRATION

### 3.1 行为规格基线

1. 贴底跟随/回底浮标（bottomInset 避让 +14px）；轮锚点跳转（尊重减弱动态）。
2. 头部菜单全链：重命名/复制 ID/受信重开×2/归档/关闭/项目三开（finder/terminal/editor）/复制路径。
3. 面板：头部开关（开=整组收起/关=Diff 打开）；多标签聚焦关闭；切会话组态存档恢复；⌘⇧D/⌘⇧A toggle。
4. 文件选择器：进入拉全量 + 客户端过滤；文件 tab 读取（readFile）。
5. 状态徽标：权限等待/压缩/生成/队列计数派生；掉线横幅进设置。
6. 横幅：crashed/compacting/retrying/queue/bash 尾部。
7. 消息流：loading 尾、空态/水化失败重试、编辑/分叉回调。
8. **批推重渲半径（新）**：流式批推只重渲舞台消息区；高度变化只重渲舞台。
9. 引导屏/启动守卫/用量页/命令面板/新建页行为不变（数据源换轨）。
10. ComposerRegion 归零 props（agents 入口走 controller）。
