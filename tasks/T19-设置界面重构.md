> 状态：已实施（真机功能走查通过，视觉对照待用户目验——本机截屏权限受限；对抗审查进行中）
> 级别：中
> 参考稿（按图片实际内容命名）：`setting-png/01-子智能体.png`（子智能体列表页）、`setting-png/02-常规.png`（常规页：语言/外观/信任/引导卡）、`setting-png/03-技能.png`（技能页）——三稿取共同视觉语言 1:1；未截图的分区（模型设置/API 密钥/权限/智能体/历史/诊断）沿用同一视觉语言

## 契约

- **零 hub 协议变更、零主进程变更**：数据全部来自既有 `LiveWorkspaceView`（providers/credentials/permissionRules/sessionRules/agents/skills/saved/preferences/diagnostics）
- 渲染层新增逻辑：
  - **分区模型**（`settings/settings-sections.ts`）：8 分区归三组导航 + 底部引导入口（纯数据，单一真相）
  - **装配 hook**（`settings/use-settings-screen.ts`）：消灭 workspace-main 对 SettingsScreen 的 ~40 props 手工接线；分区切换状态、打开重置首分区、按开即读派发（permissions/agents/skills/diagnostics）、saved 派生（pinned Set/projects 去重）、语言/重跑引导回调全部收拢
  - **语言「跟随系统」**：`strings/index.ts` 扩展 `LocaleSetting = 'system' | 'zh' | 'en'`（存储面），解析面仍是 `Locale = 'zh' | 'en'`（copy 表键不变）；system → `navigator.languages` 任一 zh 开头取 zh 否则 en；**未存储时的默认设置由 zh 改为 system**（全新安装跟随系统语言；已存 zh/en 的用户不受影响）。公共 API 收敛为 `getLocale`/`getLocaleSetting`/`changeLocaleSetting`（旧 `setLocale`/`changeLocale` 删除）
  - **主题接线**：`ThemeProvider`/`useTheme`（light/dark/system，localStorage `pai-theme`）已就绪，常规页外观分段控件直写，无新持久化
  - **重跑新手引导**：`restartOnboarding` 动作 = `updatePreferences({ onboarded: false })`（既有通路），偏好推回后 `WorkspaceScreen` 自动切回引导屏；失败推 notice
- 首分区由 `providers` 改为 `general`（常规，参考稿首位）
- strings 新 key（中英同步）：导航分组（基础设置/Agent 能力/数据与统计）、返回工作区、分区大标题+描述、外观（浅色/深色/跟随系统）、语言（跟随系统）、搜索占位、引导卡（标题/描述/按钮）、测试连接等既有 key 沿用；删除死 key `generalBunPath`/`generalHubEntry`（无 UI 消费）
- `ProviderForm` 被 onboarding 复用：props 接口保持不变，仅内部视觉重写（onboarding 不改）

## 问题域

- 处理：
  - 设置页骨架重排：左导航 ~320px（分组标题 + 选中浅灰胶囊 + 顶部「← 返回工作区」+ 底部 dashed 引导项）+ 右内容列（大标题 28px semibold + 描述行 + 内容最大 ~1000px 居中、白卡片 1px 边框圆角 12px、设置行左标题描述右控件、黑色主按钮、黑色开关）
  - 分区内新增**本地过滤**：技能搜索框（按名称/描述过滤）、模型设置搜索框（按 provider/模型过滤）——纯 UI 态，不进 store
  - 常规页：界面语言分段（跟随系统/简体中文/English）、外观分段（浅色/深色/跟随系统）、默认信任新项目开关行、底部虚线引导卡（重跑新手引导）
  - 模型设置页：默认模型下拉、provider 卡片（名称/BaseURL/模型能力摘要/key 状态徽章 + 测试连接/编辑/移除）、新增/编辑表单、添加自定义模型黑色按钮
  - 既有行为全部保留：按开即读（四分区）、provider 表单校验/逗号切分/思考视觉开关、key 不回显、两步移除确认、草稿深比较禁用保存、权限 scope 切换、置顶/resume/reveal
- 不处理（挂账）：
  - 参考稿有而本应用无数据面的分区（浏览器控制/电脑控制/记忆/插件/MCP 服务器/命令/钩子/索引库/使用统计）不还原导航项
  - 参考稿右上角「帮助」按钮不还原（无帮助体系）
  - 「跟随系统」语言不实时监听系统语言变化（启动/切换时解析）
  - hubDev（bun/宿主路径）继续无 UI（既有裁决）
  - 深色模式不做专属样式：组件全部走语义 token（bg-card/border-border/…），跟随既有 .dark 变量自然适配
  - onboarding 屏视觉不重构（仅随 ProviderForm 接口受益）
  - SegmentedControl 的 radiogroup 方向键导航（ArrowLeft/Right 焦点移动）不随本任务实现——键盘交互增强挂账后续 UI 打磨批次（当前 Tab 逐段可达，较旧版无回退）
  - provider 移除确认态聚焦「确认/取消」操作（测试连接/编辑按钮在确认态隐藏）为新 UI 有意设计；移除失败停留确认态可立即重试（与旧版一致）

## 并发/一致性预算

- 分区切换/搜索词/过滤为纯 UI 态；分区状态归 `use-settings-screen`（语言切换根级重挂载后回到首分区，与现状一致）
- 主题/语言写入都是 localStorage 同步写 + 既有广播/Provider 内部状态，无新异步面
- 重跑引导与 completeOnboarding 走同一条 `updatePreferences` 串行链，无并发新增
