## 统一工程规约（强制）

1. **单测位置**：`packages/<包>/<模块>/__test__/*.test.ts`，`bun test packages/<包>` 独立可跑；公共测试资产仅 testkit（含 fake-hub）与 T1 夹具库；禁止跨包引用他人 `__test__` 私有文件。
2. **四门**（每步提交前全绿）：`bun run lint`（oxlint --type-aware 0-0）/ `tsc --noEmit` / `electron-vite build` / `bun test`；覆盖率 行/语句/函数 ≥90、分支 ≥85，只升不降，汇报报数字。
3. **依赖白名单与环境面**：oxlint 插件 `pai/*`（`oxlint-plugins/pai/`）挂 lint 门禁，层级矩阵见方案第 1 章；packages 出现 `import 'electron'` 即红。
4. **协议边界**：hub 协议字面量（帧/命令/AgentSessionEvent 字段）只许出现在 packages/adapter、contracts 镜像、夹具库；越界即 CI 失败。hub 协议演进 → 先走 hub 仓库流程，再同一提交内同步本仓库 contracts 镜像。
5. **测试计划先行 + 对抗审查**：各任务「测试口径」先于实现；契约/并发/安全批次独立会话必审；每 bug 带回归用例。
6. **提交**：Conventional Commits + 引用任务文档节号；worktree 隔离并行；只提交自己改动；只 commit 不 push。
7. **实现纪律**：单一真相（contracts/Port）、零兼容层、一动词一文件、未实现=bug、错误 message 中性英文、文案进 strings；不写版本叙事（历史只在 changelog）。

## 已裁决记录（不再讨论）

单 pi-hub 宿主；hub 由随包 bun 二进制运行；**OS 沙箱归属 hub，Pai 不做 spawn 包裹**；**权限 = Pai 纯 UI 交互，操作经协议提交（ui_response / rules 命令 / trusted 参数）**；线程并发 Electron 客户端限流；TS 7；`@paiapp` scope；包源码直出；API schema 进 contracts；认证仅 API key（key 随渠道录入：provider-keys.json 加密 + env 注入 hub，不经 hub auth/* 通路）；Pai 的 SQLite 只存视图元数据 + 恢复快照 + 偏好 + 用量（调试缓冲不落库）。

## 外部依赖（hub 侧提供，Pai 只调用）

权限规则读写命令（rules 类）；OS 沙箱配置接口（如 hub 暴露）。hub 未就绪前，Pai 对应功能降级只读展示。
