# 移动端对话页 UI/UX 深度优化

> 状态：已核销
> 级别：小
> 范围：`apps/mobile` 对话页视觉与交互细节

## 1. 目标

对话页细节精修：统一字体层级、补齐 44pt 触控、强化代码块与权限卡交互、
统一按钮触控尺寸。面向移动交互，保持简约克制。

## 2. 审计缺陷（bw 390×844 实测）

1. 字体碎片化：10/11/12/13/14/15/16 共 7 级，无体系。
2. 触控目标不足：代码展开「展开剩余 N 行」26px、权限按钮 34px（规范 44pt）。
3. 代码块展开为裸 Text 点击区，命中面积小、无按压反馈。
4. Button small/medium 触控高 34–40px。

## 3. 设计基线

### 3.1 字体层级（tokens `type`，五级封闭）

| token | 字号/行高 | 用途 |
|------|----------|------|
| display | 25/32 | 空态主标题 |
| title | 17/24 | 顶栏标题、Sheet 标题 |
| body | 15/23 | 结果正文、用户消息 |
| row | 13/20 | 过程行、工具行、代码块、分区标题 |
| meta | 11/15 | 耗时、次要信息、状态行 |

代码块与等宽内容统一走 `row` + monospace；10/12/14/16 从 UI 铬层消失。
Markdown 标题独立内容尺度：h1 20、h2 17、h3 15、h4–6 13。

### 3.2 触控

- 所有可点元素 ≥ 44pt：代码块展开行改 Pressable 44 高；Button 文本容器 minHeight 44。
- 保留按压反馈（rowPressStyle 语义）。

### 3.3 细节

- 代码块头部：标题（row 粗体）+ 语言/行数（meta），右侧 chevron 随文字；
  展开/收起行独立 44pt Pressable。
- 权限卡：标题 title、命令 mono row、按钮 ≥44pt，间距接节奏表。

## 4. 问题域

处理：tokens、button、code-block、thinking/tool-group/status-line、
process-fold、chat-header、user-message、markdown-block、permission-card、测试。
不处理：导航结构、新功能、跨应用改动。

## 5. 测试口径

- 字体 token 封闭性断言；关键组件字号映射断言。
- 代码展开行、Button 触控 ≥44pt 断言。
- 既有交互回归全绿；bw 390×844 视觉走查。

- [x] 所有可点目标 ≥44pt，含代码展开与权限按钮。
- [x] 代码块展开行具备完整按压语义与反馈。
- [x] 四门、覆盖率、bw 走查如实核销。
