## 1. DESIGN（设计基线）

### 1.1 外部契约

**组件面**

| 组件 | props | 说明 |
| --- | --- | --- |
| `ComposerRegion`（新，`composer/composer-region.tsx`） | **1**：`onOpenAgents: () => void` | 线程页输入卡区域（方法论 §3 区域 0–3 props 带内；面板开合 hook 属 WorkspaceMain 装配实例，单例化挂账后续任务）。其余全部自订阅；textarea 经对象 ref + 挂载 effect 注册 controller（子件只认对象 ref——回调 ref 会废补全采纳后的光标定位） |
| `composer.tsx` 包装层 | **删除** | 唯一消费方换区域；40 props 与 9 个 label props 随之消亡（Region 直读 copy；noModelsLabel 保留 hostDown 三态判定，hostDown = hostPhase null/failed） |
| 四个共享子件 | 不变 | 注入面保留（双页差异面） |
| ThreadStage | 不变 | fork/edit 回调由 WorkspaceMain 喂模块函数引用（稳定） |

**Region 订阅面（细粒度清单）**

- live store：`activeThreadId`、`sessions[tid]`（model/thinkingLevel/sessionPath/state）、`threads[tid]`（streaming/bashRunning/queue→generating/agentsActive 派生）、`models`、`stats[tid]`、`sessionRules`、`hostPhase`、`commands`、`effortLevels`、`activeCwd`（经 sessions）
- ui store：`composerDraft`/`drafts[tid]`（value）、`composerRestore`（token 订阅）、`branchRevision`（分支视图失效代次，喂 Region 内 useGitBranches）、`confirmStop` 由确认条消费（Region 不订）
- queuedDrafts 单例：**按键取**——`useSyncExternalStore(subscribe, () => snapshot()[tid] ?? EMPTY_QUEUED_LIST)`（EMPTY 模块级恒定；后台线程的 stage/remove/flush 不进 Region 订阅面）
- `useGitBranches` 拉取 hook **居留 Region**（副作用居留订阅点）：失效信号 `branchRevision` 迁 ui store（见下）

**store 与单例面（新增/迁移）**

- live store +2 字段：`commands: readonly CommandView[]`、`effortLevels: readonly string[]`（初始 []）。写权不变：useLiveWorkspace 拉取 effect 居留原处写 store（先例 agentDefinitions）。**切会话同步清理**：`setActiveThread` 内同清两字段（对齐 store.ts 既有「防渲染帧残留一帧」先例，不等 effect）。
- ui store +3 字段：`confirmStop: boolean`、`composerRestore: { token; images } | null`（一次性信号，token 递增即并入；PromptCard 重挂载初始 token 吞并行为保持不变——迁移不改该语义）、`branchRevision: number`（分支视图失效代次）。动作：`setConfirmStop`、`setComposerRestore(images)`、`bumpBranchRevision()`。`reset()` 收编。
- `composer/composer-controller.ts`（模块单例，跨区通道，六个函数）：`registerComposerTextarea(el)/unregisterComposerTextarea(el)`（注册对）、`focusComposer()`、`restoreComposerImages(images)`（写 ui store 信号）、`insertIntoDraft(text)`（**前缀拼接**语义：非空草稿补尾空格 + 聚焦——palette `/skill ` 插入链）、`setDraftAndFocus(text)`（**替换**语义——fork 回填/编辑重发链）。后两者读 live store 真相寻址活跃线程。
- `composer/submit-composer-draft.ts`（同构迁入 workspace-main submitDraft）：流式中非直执行 → queuedDrafts.stage（threadId/sessionPath 寻址）+ clearDraft；否则 submitDraftText 附件转换直发；streaming 判定读 store 真相。
- `composer/stop-or-abort.ts`（同构迁入）：**读 store 真相**（threads 活跃 streaming/bashRunning/agentsActive/generating）三态：bash→abortBash；agentsActive 且 generating→setConfirmStop(true)；否则 stopActiveTurn。与 Esc 表尾同语义但输入域不同（Esc 是渲染帧输入、M3 已固化；按钮路径取真相——瞬时分叉如实记载，注释互指）。
- `composer/composer-selection.ts`（派生下沉）：`composerSelectionOf(models, stats, sessions, effortLevels, threadId)`（buildComposer 语义原样；签名内化 session 查找；**无 threads 参数**——旧函数体对 thread 形参零引用）。useLiveWorkspace 与 Region 共用。
- `screens/workspace-fork.ts`（重写 use-fork-message）：模块函数 `forkUserMessage/editUserMessage`；restore hook state 删除（信号走 controller→ui store）；草稿与聚焦走 controller（editUserMessage = setDraftAndFocus；fork 回填 = restoreDraft(新线程槽) + restoreComposerImages + focus）。
- **确认条编排归属**：StopConfirmBar 渲染留 WorkspaceMain，`onConfirm` = `setConfirmStop(false) + workspaceActions.stopActiveTurn()`、`onCancel` = `setConfirmStop(false)`（内联直调，与 Esc 的 execute-confirmed-stop 分发同语义两处，注释互指）。
- `LiveWorkspaceView.thinkingLevels` **删除**（全仓零消费方——死视图字段，本期顺带清理）；`commands` 字段保留（palette 共用）改读 store。

### 1.2 内部问题域

**处理**：Region 自订阅 + 编排下沉 + controller 通道 + 三处数据源归位（confirmStop/composerRestore/branchRevision → ui store；commands/effortLevels → live store；thinkingLevels 死字段删除）+ 包装层 40 props 清零。

**明确不处理**（归属）：ThreadStage/SettingsScreen 区域化；useLiveWorkspace 溶解（仅两前置）；StopConfirmBar 渲染位置；queued-flush 连接器与 queuedDrafts 内部；新建任务页装配；**usePanelTabs 面板系统单例化**（Region 的 `onOpenAgents` 装配 prop 挂账此项解除）。

### 1.3 并发与性能预算（违反 = 缺陷）

- **敲键重渲半径 = Region 子树**：WorkspaceMain 不再订阅草稿——敲键后 Region 外零重渲（B-keystroke 用例 1）。
- **无关线程事件零穿透**：后台线程的 sessionUpdated/流式批推/**排队暂存变化**不重渲 Region（订阅面细粒度 + queuedDrafts 按键取；B-keystroke 用例 2 把后台排队变化纳入输入）。
- 全局定时器个数不变；controller/编排模块零渲染期副作用；store 动作零 IO。

## 3. MIGRATION（迁移单元：线程页输入卡交互面）

### 3.1 行为规格基线

1. 草稿按会话隔离、语言重挂载存活（既有）；**敲键与无关线程事件只重渲输入卡区域（新增回归）**。
2. 提交三分支：流式中普通消息→本地暂存（卡片堆 + 轮末冲刷；resolve true 清附件、草稿即时清）；`! ` 直执行与行首斜杠命令不暂存直发；空闲直发（附件转 ImagePayload）。
3. 停止三态（按钮路径读 store 真相）：bash 在途→中止；在途子代理且生成中→确认条；否则直停。确认条确认=停+关条、取消=关条、Esc=执行（Esc 链既有帧输入契约）。
4. palette 插入 `/skill `（非空草稿补尾空格）→ 草稿更新 + 聚焦。
5. fork：autoResend 原样直发不回填；否则 restoreDraft(新线程槽) + 图片一次性信号 + 聚焦（替换语义）。
6. 附件 scope=threadId 切换即清。
7. @ 搜索按当前会话 cwd；斜杠补全目录随会话拉取、切会话清空（store 同源）。
8. 无模型（含 hostDown）→引导文案点击进设置；思考档无选项→禁用原因。
9. 排队卡片三动作：立即发（steer）/编辑回填（含图片信号）/移除。
10. 用量环：stats 未拉取不可点；contextUsed 取活跃会话 stats。
