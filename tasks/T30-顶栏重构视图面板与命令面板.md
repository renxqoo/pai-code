# 顶栏重构、视图面板系统与命令面板（T30）方案

状态：草稿 → 定稿（用户裁决齐备：多标签面板容器 ✅、命令面板底部 ✅、范围 = 第一+第二梯队 ✅、终端/PDF/图片/网页视图与 git commit/push/PR 不做 ✅、导出等 hub 能力不写占位 ✅）。

## 背景

顶栏 6 控件中 4 个为 noop 装饰（更多操作 / 打开主键 / 提交推送建 PR / 添加面板），「提交推送建 PR」prominence 错位且无任何 git 实现；会话级动作（重命名/关闭/受信重开）散落或缺失；状态（运行中/等权限/压缩中）无常显面；右侧面板为单槽位（agents/diff 二选一）。竞品收敛结论（CC 桌面/Codex app/Zed）：标题点改、状态常显、变更角标、本机打开、命令面板是桌面 Agent 客户端的标配。

## 处理什么

1. **顶栏诚实化**：删三个假按钮（提交推送 PR、独立「打开」分裂按钮、「更多操作」Plus）；「新建」接 `newTask.enter`；「切换分栏」按钮删除（被视图系统吸收）。
2. **身份区**：项目名 chip 下拉（在访达/终端/编辑器中打开、复制路径）；标题点击行内改名（`session/setName`）；状态 chip（等待权限/压缩中/运行中/排队中/空闲，点击滚动到消息流底部）。
3. **变更角标**：`collectThreadDiff` 的 `+n −m` 常显于顶栏，点击开 Diff 面板。
4. **会话菜单 ⋯**：重命名、复制会话 ID、以受信/非受信模式重开、归档、关闭会话。
5. **多标签面板容器**：PaneRegistry + tab 条；diff/agents 迁入为单例 tab；新增文件 tab（代码查看器 + Markdown 预览，md 文件带预览/源码切换）；面板状态按会话记忆（uiState 模块单例，同侧栏几何档位）。
6. **命令面板**：⌘P 底部居中上弹浮层；分组 = 动作 / 会话 / 文件（file/search → 文件 tab）/ 斜杠命令（填入 composer）/ 设置跳转。
7. **快捷键**：⌘⇧D 切 Diff、⌘⇧A 切子代理（进 cmd-hotkeys 纯函数）。
8. **归档**：偏好 `archivedSessions`（sessionPath 键，同 pinnedSessions 模式）；侧栏过滤 + 设置页历史「已归档」分区可恢复。

## 不处理什么（归属写明）

- 终端/PDF/图片/网页视图：不做（PaneRegistry 类型面留扩展：`PanelTab.kind` 为封闭枚举，未来加 kind 即加 pane）；系统兜底存在（系统预览/浏览器/Terminal）。
- Diff 面板内 commit/push/PR：不做（git port 不扩展，`git-branches.ts` 维持 list/checkout）。
- 会话导出：等 hub 侧能力（T11 N4）；**不写 capability 门控占位菜单项**——hub 契约落地时随契约加项。
- 会话删除 / checkpoint：hub 无命令（T11 N3），维持现状。
- 消息正文内文件路径点击打开：不做（纯文本路径识别启发式误报率高；入口 = 面板视图菜单「打开文件…」+ 命令面板文件组 + Diff 文件列表行点击）。
- 文件写入/编辑：`file/read` 只读。
- 面板拖拽排序、并排双 pane：不做（tab 单活跃）。
- 归档会话的批量管理/自动归档（PR 合并后等）：不做。
- palette 使用历史持久化：不做（cmdk 内建匹配排序）。

## 外部契约（contracts/api.ts 单一真相新增）

### `shell/open`
```ts
params: { cwd: string(≥1), target: 'finder' | 'terminal' | 'editor' } → result: null
失败 reason: cwd_not_allowed | terminal_not_found | editor_not_found | open_failed:<exit|timeout|spawn|output_too_large>
门禁：isKnownCwd（与 file/search 同闸）；动作落审计 audit(`shell_open:${target}:${cwd}`)。
```
主进程 `main/open-location.ts`（run/platform/env 注入替身保可测）：
- finder：darwin `open <cwd>`；win `explorer <cwd>`（退出码 1 = 窗口已开，成功语义）；linux `xdg-open <cwd>`。
- terminal：darwin `open -a Terminal <cwd>`；win `cmd /c start wt -d` 失败回落 `cmd /c start cmd /K cd /d`；linux 依次探测 `x-terminal-emulator`/`gnome-terminal`/`konsole`（`--workdir`），全失败 `terminal_not_found`。
- editor：候选 `code`/`cursor`/`$VISUAL`/`$EDITOR`（GUI CLI 优先、去重）逐一 `--version` 探活，结果进程内缓存；全缺失 → `editor_not_found`（**不静默换 finder**，渲染层提示装 CLI）；执行 `<cmd> <cwd>`。
- 所有 execFile 无 shell、超时 5s、maxBuffer 64KiB、windowsHide。

### `file/read`
```ts
params: { cwd: string(≥1), path: string(≥1) } → result: { content: string, truncated: boolean, size: number }
失败 reason: cwd_forbidden | invalid_path | path_forbidden | not_found | cwd_not_found | binary_file | read_failed
```
主进程 `main/file-read.ts`（fs 面注入可测）：
- path 必须相对（拒绝对对路径与 `..` 段）、任何段不得以 `.` 开头（与 file/search 枚举面一致）；
- realpath 归一后必须仍在 cwd 的 realpath 之下（防符号链接逃逸，macOS /tmp→/private/tmp 同 api-routes 既有归一语义）；
- fd 限长读：内存上界 2 MiB；`size` 回磁盘真实字节数，超限 `truncated=true`（渲染层提示被截断，比拒绝更适合查看器场景）；
- 二进制嗅探：前 8 KiB 含 NUL → `binary_file`；读取 utf8。

### `app/setPreference` 扩展
`archivedSessions: z.array(z.string()).optional()`；`PreferencesViewSchema` 加 `archivedSessions: z.array(z.string())`（file-settings 偏好文件同步加字段，缺省 `[]`）。

### 渲染层内部契约（非 IPC）
- `panel/panel-state.ts`：`PanelTab = { id, kind: 'diff'|'agents'|'file', cwd?: string, path?: string }`；`PanelState = { tabs: readonly PanelTab[], activeId: string | null }`；纯函数 `openPanel(state, tab)`（同 id 幂等并聚焦）、`closePanel(state, id)`（关活跃则焦点移邻 tab，全关 = null）、`focusPanel`、`togglePanel`（开则关/关则开并聚焦）。单例 kind 的 id == kind；file id = `file:${cwd}:${path}`。
- `thread/thread-status.ts`：`threadStatus({ permissionWaiting, compacting, generating, queueCount }): { kind: 'idle'|'queued'|'running'|'compacting'|'permission' }` 纯函数（优先级 permission > compacting > running > queued > idle）。
- `hooks/cmd-hotkeys.ts`：`resolveCmdHotkey` 扩展 `'palette'`(⌘P) / `'toggleDiff'`(⌘⇧D) / `'toggleAgents'`(⌘⇧A)；shift 组合新增、Alt 仍不劫持。
- `screens/esc-action.ts`：`EscState` 加 `paletteOpen: boolean`（链位：dialogs 之后、usage 之前——palette 是顶层浮层但模态对话框优先）；`SidePanel` 类型退役，改 `panelOpen: boolean`。

## 并发/一致性预算

- `shell/open` 与 `file/read`：单次调用 <10s/10ms 量级；execFile 全部带超时；无长驻进程、无定时器。
- 文件 tab 读取：打开时一次 fetch + 手动刷新按钮；不轮询、不 watch（fs.watch 属终端/PDF 同级的后续增量）。
- 面板状态记忆：uiState 模块单例（与草稿/侧栏几何同档），不落盘；语言切换重挂载不丢。
- palette 文件组：输入 ≥1 字符才触发 `file/search`，300ms 去抖，在途请求世代号丢弃过期应答（同侧栏搜索既有语义）。

## 测试口径

- 契约级：API_METHODS 表新增项与 zod schema 一一对应；`shell/open` target 枚举封闭；`file/read` reason 词表 == 本文档词表（表驱动遍历）。
- open-location：平台矩阵（darwin/win/linux × finder/terminal/editor）注入 run 替身断言参数形态；win explorer 退出码 1 成功语义；win terminal wt→cmd 回落链；editor 探测缓存（--version 只探一次）；候选全败 editor_not_found（不换 finder）；超时/进程级异常 reason 映射。
- file-read：越界（`..`/绝对/点段/符号链接逃逸）全拒；not_found/cwd_not_found/binary_file/目录 invalid_path；2MiB+3 字节截断（size=真实值、truncated=true、内容=前 2MiB）；路径合法性表驱动（含中文/空格/NUL/控制字符）。
- panel-state：开/关/焦点/幂等/邻位焦点迁移/单例与 file id 共存表驱动；toggle 语义。
- thread-status：五态优先级表驱动（含组合态：permission+compacting 同时）。
- cmd-hotkeys：⌘P/⌘⇧D/⌘⇧A 命中矩阵；Alt 不劫持；大小写。
- esc-action：paletteOpen 链位（dialog > palette > usage > …）。
- palette-groups：分组构建/空态/文件组去抖世代丢弃（纯函数 + hook 假时钟）。
- 归档过滤：sidebar-view-model 排除 archivedSessions；设置页历史分区切分/恢复回调。
- thread-header：改名提交/取消/空值不提交；菜单选择回调逐项；变更角标数字渲染；状态 chip 文案。
- 回归：旧 keys（addAction/open/commitPushPr/openMenu/commitMenu/tabAdd/toggleSplitView）从 strings 删除后 `typeof en/zh` 对齐编译期保证。
