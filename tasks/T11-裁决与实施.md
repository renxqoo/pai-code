## 五、批次 1d 方案（中级 · design-b 紧凑版）：C1 斜杠/技能自动补全

### 契约

- 命令白名单：`PaiCommandType` 增 `get_commands`（hub 命令 `threadId` 参数；响应 `{ commands: [{ name, description?, source }] }`，source ∈ extension/prompt/skill，skill 名带 `skill:` 前缀——hub design.md:97 + command-listing.ts 实测形状）。
- API：新方法 `'command/list'`：params `{ threadId }`，result `CommandView[]`；`CommandViewSchema = { name: string; description: string | null; source: 'extension' | 'prompt' | 'skill' }`（description 缺失收窄为 null）。
- adapter：`sessionCommands(raw)` 收窄（垃圾条目丢弃，source 词表外丢弃）。
- 渲染层：补全触发纯函数——`activeSlashQuery(text, caret): string | null`（`/` 位于行首或空白后、至 caret 无空白才激活，返回 `/` 后的查询串）；`applySlashSelection(text, caret, name)` 把该 token 替换为 `/name␠` 并给新 caret；`filterSlashItems(items, query)` 大小写不敏感子串。
- 交互：composer 内 `/` 触发弹层（锚输入框上方），↑↓ 循环高亮，Enter/Tab 采纳（Enter 采纳时 preventDefault 不提交表单），Esc 关闭（stopPropagation，不让全局 Esc 停止生成外溢），点击条目采纳；输入空格或删掉 `/` 关闭。数据随 activeThread 切换重拉（与 thinkingLevels 同型，hook 局部态）。
- 不处理：`@` 文件引用（C2）、`$` 独立技能触发（`/` 前缀已覆盖 skill: 条目）、补全条目的参数提示（协议无参数形状）。
