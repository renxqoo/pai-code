## 三、批次 1b 方案（小级 · design-a）

> 状态：定稿
> 级别：小（纯渲染层加法 + 既有 action 暴露；无新外部契约）

### 契约

- `filterSessions(sessions: readonly SessionCardModel[], query: string): readonly SessionCardModel[]`（新文件 `sidebar/filter-sessions.ts`）：trim 后空查询原样返回（同引用）；非空查询按 `title` / `projectName` 大小写不敏感子串匹配。
- `LiveController.compact(threadId): Promise<string | null>`（原 `Promise<void>` 升级）：成功返回 null，失败返回原因（与 `submitDraft` 同形）；hook 层转 notice。
- `LiveWorkspaceView.actions` 新增 `renameSession(threadId, name): Promise<boolean>`（controller 已有 `session/setName` 通路，hub 回推 `session_info_changed` → `sessionRenamed` 事件 → store 更新标题，无乐观更新）。
- UI 契约：搜索行受控输入（value/onChange/清空按钮）；会话卡 hover 重命名（铅笔入口 → 行内输入，Enter 提交 / Esc 取消 / blur 提交，trim 空值=取消）；assistant 正文块 hover 复制按钮；composer 动作行新增「压缩」图标按钮（compacting 时禁用）；access 选择器全链路删除（含 demo 夹具与 `composer.accessMenu` 文案）。

### 问题域

- 处理：过滤会话列表、重命名会话标题、复制 assistant 正文、手动压缩上下文、删除假 access 选择器。
- 不处理：跨会话全文搜索（属 A2/N 范畴，消息内容经标题间接覆盖）；重命名失败重试 UI（notice 提示即可）；compact 拒绝原因的专项文案映射（hub 无稳定字面量，通用原因提示，出现稳定字面量后补回归）；排队消息管理（A7）。

### 裁决

- 全部为讨论已定默认裁决的落地（见上表 #5/#8），用户已确认方向（2026-09-08 会话）。

### 测试口径

- `filter-sessions`：空查询同引用返回 / 空白串等价空查询 / 大小写不敏感 / title 命中 / projectName 命中 / 无命中空数组 / 中文与 unicode。
- `controller.compact`：成功 → null；失败 → 透传原因（fake client 表驱动）。
- `controller.renameSession`：成功 → true 且发出 `session/setName`；失败 → false。
- store `sessionRenamed` 折叠已有覆盖（store.test.ts）；组件视觉交互不新增测试装置，由既有 demo 装置回归。
