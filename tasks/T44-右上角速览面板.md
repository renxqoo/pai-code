# 右上角速览面板（Git · 进程 · 智能体）方案

> 状态：已实施（裁决 A–G 按默认裁决推进——用户指示中途不停直至验收；实施推翻方案处在同提交内同步）
> 级别：中（跨 contracts / api / renderer；契约新增：`todo/snapshot` 放行 + `git/status` 只读增强；无不可逆存量变更）
> 工作树：`agent-app-t44` @ `t44-pulse-panel`

## 0. 需求原文与扩展

用户需求（原文要点）：

1. 聊天右上角固定定位面板，参考图形态：可收缩；
2. 看 Git 信息、文件修改；
3. 当前 todo 列表进度——**对话列表不再展示 todo 工具调用**（映射层过滤），改由面板集中展示；
4. 面板底部：有子 agent 执行时展示「正在运行」状态；
5. 设计要求：界面 UI、功能面（含用户未尽部分）、交互、展示信息、组件化、shadcn 风格、底层组件库归属。

本方案在上述基础上扩展的功能面（§1.3 各区「扩展」项）：分支切换、ahead/behind、变更点击联动 diff 面板、todo 三态进度与归属、子 agent 计时/耗时、收起态胶囊聚合计数、空态/错误态、分区级折叠。

## 1. UI 设计

### 1.1 定位与形态

- **常驻浮层**：固定在会话舞台右上角。锚在 `screens/workspace-main.tsx` 的 `relative flex-1 flex-col` 容器内（`absolute top-12 right-3 z-30`），天然避让两处既有右上角控件：thread-header 的 PanelRight 开关按钮与 Windows caption 按钮（`layout/window-caption-buttons.tsx`），且右侧 Dock（PanelLayer）展开时面板随舞台收缩，不被遮挡。
- **两种形态**：
  - 展开态：宽 320px，`max-h-[60vh]` 内滚；`rounded-2xl border border-border bg-popover shadow-lg shadow-black/5`（与 AnchoredPanel popup 同一观感 token）。
  - 收起态：胶囊 chip（参考图 3 形态），贴同位置，点击恢复展开。
- **视觉语言**：shadcn token（bg-popover / border-border / text-muted-foreground），图标 lucide-react，行高紧凑（参考图密度：icon + 标签 + 右侧数值/chevron）。

### 1.3 分区与展示信息

**A. Git 区**（数据源：新 `git/status` + 既有 `git/branches`、`git/checkout`、`git/graph`）

| 行 | 展示信息 | 交互 |
| --- | --- | --- |
| 更改 | 文件图标 + 「更改」+ `+N`（绿）`−M`（红）；tooltip 显示变更文件数 | 点击 → 打开右侧 Dock diff tab |
| 分支 | git-branch 图标 + 当前分支名 | 下拉：分支列表（含当前标记）、点击切换（`git/checkout` 沿用 `dirty_worktree` 守卫）（裁决 E） |
| 上游 | `↑ahead ↓behind` | 无远端/无上游隐藏 |
| 图谱入口 | 「打开 Git 图谱」 | 打开既有 T36 Git 图谱视图 |

扩展：非 git 仓库 → 整区收为单行灰字「非 Git 仓库」；`git/status` 失败 → 行内灰字 “Git 状态不可用” + 点击重试。

**B. 进程区（todo 进度）**（数据源：`todo/snapshot` 事件，last-wins 全量快照）

| 元素 | 展示信息 | 交互 |
| --- | --- | --- |
| 头行 | 「进程」+ `n/m`（m=任务总数，n=completed 数；全完成时绿） | 点击折叠分区 |
| 任务行 | 状态图标 + subject；completed=删除线灰、in_progress=常规字重高亮、pending=灰；`owner` 存在时行尾 type-pill 显示归属（子 agent 名） | 点击行展开/收起 description（裁决 C）；tooltip 显示 activeForm |

排序 = 快照原序（x-harness 词表顺序即语义）；依赖边 `edges` 本期不展示（不处理）。

**C. 智能体区**（数据源：既有 live store `agents` / `SubagentModel`）

| 元素 | 展示信息 | 交互 |
| --- | --- | --- |
| 头行 | 「智能体」+ `k 工作中`（k=running 数；0 不显示角标） | 点击折叠分区 |
| agent 行 | 状态点/小 spinner + 名称 + work 摘要一行 + duration-tag 耗时 | 点击 → 打开 Dock agents tab 并定位该 agent |

**D. 底部运行条**（有 running 子 agent 时固定在面板底部）

- spinner + 当前 agent 的 activeForm/work 摘要一行 + 计时；多个运行中时显示 `+N`，点击 → agents。
- **面板收起时**：同信息变为浮动胶囊（参考图 2），挂在收起 chip 下方；无运行中则不显示（不摆假控件）。

**E. 收起态 chip**

- 三段聚合：`更改 +N −M │ n/m │ ◌k`（某段无数据则该段隐藏；全空时只留 `速览` 标签）。
- 点击展开；hover 出 tooltip 三行摘要。

### 1.4 交互细节

- **折叠两级**：面板级（展开 ⇄ chip，标题栏 ⤡）与分区级（标题行 chevron）；状态持久化进 `ui-store`（`pulse: { open, sections: { git, todo, agents } }`），重启保留。
- **刷新策略**：事件驱动，无轮询定时器。`todo/snapshot`/`agent/*` 直推 store；git 计数在 `tool/call|result`（文件修改类工具）后标记过期，面板展开或过期后下一帧重取 `git/status`；沿用 `use-git-branches` 的「过期响应丢弃 + 在飞去重」模式。
- **空态矩阵**：非 git 仓库（Git 区收单行）/ 无 todo（进程区整体隐藏）/ 无子 agent（智能体区整体隐藏 + 运行条不显示）/ 全空（面板只剩标题栏，chip 只留标签）。
- **键盘与无障碍**：全部行可 Tab 聚焦、Enter 触发；分区头 `aria-expanded`；chip `aria-label` 含三段摘要。
- **动效**：面板开合 scale/opacity 过渡（AnchoredPanel 同款 data-[starting-style]），分区折叠高度过渡；无花哨特效。

### 1.5 对话列表过滤（todo 工具调用下线）

- `thread/tool-kind.ts` 词表新增 `'todo'` 类（覆盖 x-harness todo-tools 全部工具名词表）。
- **映射层分流**（单一真相，live 与历史同轨）：`entries-mapper.ts` / `event-mapper.ts` 对 todo 类 `tool/call|result` 不产生渲染条目（WAL cursor 照常推进）；折叠层不收编此类块。
- todo 面板数据只吃 `todo/snapshot` 事件，不从工具调用反推。

## 2. 契约（外部契约变更）

1. **contracts/hub-events.ts**：`HubEventName` += `'todo/snapshot'`；新增镜像 schema（形状对齐 x-harness `session/src/types.ts` 的 `TodoSnapshotEventData`）：

```ts
export interface TodoSnapshotTaskData {
  id: string; subject: string;
  status: 'pending' | 'in_progress' | 'completed';
  description?: string; activeForm?: string; owner?: string;
  metadata?: Record<string, unknown>;
}
export interface TodoSnapshotEventData {
  seq: number;
  tasks: readonly TodoSnapshotTaskData[];
  edges: readonly (readonly [blocker: string, blocked: string])[];
}
```

2. **contracts/api.ts**：新增只读 verb `git/status`：

```ts
'git/status': { in: { cwd: string }; out: GitStatusView }
interface GitStatusView {
  isRepo: boolean;
  current: string | null;
  files: { path: string; kind: 'modified'|'added'|'deleted'|'renamed'|'untracked'; additions: number; deletions: number }[];
  additions: number; deletions: number;
  ahead: number; behind: number;
}
```

   非仓库 = 空形态（isRepo:false + 其余零值），与 `git/branches` 同规；错误沿用 `GitExecError` 四值。实现 = `git status --porcelain` + `git diff --numstat`（含 staged）+ `git rev-list --left-right --count`。

3. **UiEvent**：新增 `todoSnapshot` 载荷（= `TodoSnapshotEventData`）；WAL 恢复经 `session/entries` 结果新增的 `todo` 字段（本窗口内最后一条快照；窗口内无快照 = null，不清既有快照——调用方仅非空时覆盖）。
4. **渲染层内部契约**：`live-store` 新增 `todos` slice（by thread，last-wins 覆盖）；新增 `hooks/use-git-status.ts`；`ui-store` 新增 `pulse` 切片。

## 3. 问题域

处理：§1.3 全部；`git/status`、`todo/snapshot` 通路；消息流 todo 工具条目过滤。

不处理（归属）：

- **git 提交/推送写能力**（裁决 A：默认本批次不做）——现状是只读纪律（`live/git-actions.ts:7`），写 verbs + 信任/权限面属独立批次（建议 T45）；
- todo 任务编辑/增删/拖拽排序——纯只读展示；依赖边 `edges` 可视化——后续增强；
- 面板拖拽/停靠/多实例——右侧 Dock（PanelLayer）体系已覆盖深度面板需求；
- merge/conflict/stash 状态细节——本期只显示计数与分支；
- 多仓库/多 cwd——沿用单会话单 cwd 既有语义；
- 子 agent 详情/steer——保留既有 Agents Dock，本面板只做状态与跳转。

## 4. 并发/一致性预算

- **零新增定时器**；`git/status` 在飞去重 + 过期响应丢弃（同 `use-git-branches` 先例），触发频率 ≤ 工具结果到达 + 手动重试。
- `todos` slice：每快照 O(tasks) 全量替换，单会话在飞快照 ≤ 数十；不累积历史。
- 面板渲染 O(todos + agents + git.files)（files 在数据源侧截断：`STATUS_FILES_LIMIT=200` + `fileCount`/`truncated` 字段，计数仍全量）。

## 6. 测试口径（先于实现）

- **契约级**：`TodoSnapshotTaskData.status` 三值穷举；`GitStatusView` 非仓库空形态 / 单边增删 / untracked 行数为 0 表驱动；词表闭包（导出工具名词表 == 过滤词表）。
- **映射**：todo 类工具 `tool/call|result` 不产生渲染条目（表驱动工具名，含历史读取与 live 两路）；`todo/snapshot` last-wins 恢复（乱序 seq / 断尾缺快照 / 空 tasks）。
- **组件**：collapsible-section 受控开合 + aria；diff-stat 0/单边/双边；icon-badge 0 隐藏；todo-row 三态渲染 + owner pill；pulse-chip 三段聚合与缺段隐藏。
- **组装/边界**：空态矩阵四象限；git 失败重试；过期 git 响应丢弃；files 200 截断；多个 running 子 agent `+N`。
- **回归**：开发中发现的每个 bug 一个回归用例（用例名注明症状）。
- **e2e（跨进程，复用 fake-hub 夹具）**：发 `todo/snapshot` 序列 → 面板进程区计数与行断言；发 todo 工具调用序列 → 消息流无条目断言；spawn/finish 子 agent → 运行条/胶囊出没断言。

## 7. 实施顺序

1. **M1 契约与数据通路**：contracts schema + `git/status` verb + event-mapper 放行 `todo/snapshot` + 两映射器过滤 todo 工具 + live-store todos slice + 恢复折尾。验收：映射层测试绿 + 四门。
2. **M2 底层组件**：`collapsible-section` / `diff-stat` / `icon-badge` / `floating-panel` 进 packages/ui，含组件测试。验收：四门。
3. **M3 面板装配**：pulse-panel 各分区 + chip/运行条 + ui-store 持久化 + strings + 空态/错误态。验收：组装测试 + 四门。
4. **M4 收口**：e2e 旅程 + 对抗审查（独立会话审 diff + 本方案）+ 覆盖率只补不降 + 验收清单核销。
