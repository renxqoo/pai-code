# 新会话目录选择（原生文件夹选择 + 已知项目快捷） 方案
> 状态：已实施（对抗审查 11 项处置完毕）
> 级别：中

## 契约

- 新 API `'dialog/pickDirectory'`：
  - params：`{ defaultPath?: string }`（`.strict()`；省略时由主进程用当前活跃会话 cwd 之外的装配缺省——由渲染层显式传入，主进程不猜）
  - result：`z.string().nullable()`——选中目录的绝对路径；`null` = 用户取消/关闭对话框
  - 错误形态：沿用 `{ok:false,reason}`；本命令唯一失败面为装配缺失（`dialog_unavailable`）
- 已知项目目录数据**零新契约**：复用既有 `app/bootstrap`（活跃会话 cwd）与 `session/listSaved`（历史 cwd），渲染层去重合并
- 副作用：无（纯选择；不创建会话、不落盘）

## 问题域

- 处理：打开系统目录选择对话框（单选、可新建目录）并回填输入框；已知项目目录一键选中
- 不处理：
  - 目录有效性/权限校验——归属 hub `thread/start`（错误经通知条呈现，文案映射已存在）
  - 输入自动补全——裁决不做（与快捷列表重复，见裁决）
  - 记住「上次选择目录」持久化——defaultPath 每次由调用方（当前活跃会话 cwd / 输入框现值）决定，不加存储

## 并发/一致性预算

- 对话框为模态系统面板；在途期间渲染层 await 等待，无定时器、无重入保护需求（按钮 busy 态防重复触发）
- 取消路径只有一种形态：返回 null，输入框保持不变

## 拆分

- `packages/contracts/src/api.ts`：`dialog/pickDirectory` schema（参数/结果单一真相）
- `apps/electron/src/main/api-routes.ts`：路由 + `ApiRouteDeps.pickDirectory` 注入点（**不 import electron**，与 `revealPath` 同模式）
- `apps/electron/src/main/index.ts`：装配 `dialog.showOpenDialog`（`openDirectory`，attach 到主窗口；模态）
- 渲染层：`use-live-workspace` 增 `pickDirectory` action；`NewThreadModal` 增「浏览…」按钮 + 已知目录 chips；目录合并去重抽纯函数 `projectDirsOf(sessions, saved)`

## 实施顺序

1. contracts + api-routes 路由 + 装配注入（含契约单测、路由单测）
2. 渲染层：纯函数 + modal UI + action 接线（含纯函数单测）
3. 实机验证（原生对话框 + chips 回填）+ 对抗审查

无过渡态（纯加法，单轨）。

## 裁决

- **默认裁决（否决窗口）**：同时做「原生文件夹选择对话框」与「已知项目目录快捷列表」；不做输入自动补全。多选提问未获答复，按推荐组合推进。
- defaultPath = 输入框现值（非空时），否则不传（系统缺省位置）。
- 已知目录 chips 上限 6 条（按最近活跃排序），更多走浏览对话框。
- 对话框可浏览任意目录（与手输路径等价；会话能力仍受 file/search 的 cwd 门禁约束）；主进程单飞防并发叠弹。

## 对抗审查处置（已实施轮）

- P1×2 修复：Esc 分发链加 newThreadOpen 分支（不再穿透触发底层停止/清队列）；onSubmit 加 busy/picking 闸（防双发 session/start）。
- P2 修复：pickDirectory 失败与取消区分（失败走通知条）；busy/picking 互斥与重开复位（取消按钮 busy 禁用）；打开瞬间才重置表单（defaultCwd 异步回填不覆盖输入）；目录键尾斜杠归一；basename 兼容 Windows 分隔并统一单一真相；saved 视图 memo 化；主进程对话框单飞 + isDestroyed 兜底；schema 负路径与 limit 边界用例补齐。
- 已知限制（留档）：chips 去重不做符号链接 realpath 归一（渲染层无文件系统面；/tmp 与 /private/tmp 形态可能各占一位——hub 侧 file/search 门禁已做 realpath，功能不受影响）。

## 测试口径

- 契约：params 空对象合法、defaultPath 可选、未知键拒绝；result 仅 string|null
- api-routes（fake 注入）：透传返回值 / 取消 null / 注入缺省 `dialog_unavailable`
- 纯函数 `projectDirsOf`：sessions+saved 合并去重、最近优先、空输入空数组
- 表驱动：pickDirectory 参数矩阵（{}/{defaultPath}/坏类型）
