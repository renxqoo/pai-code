# T6 · 对话框桥与权限交互（DialogBridge / trusted 审批 / rules 协议调用） 方案

> 状态：草稿（待评审定稿）｜ 级别：中 ｜ 波次：2 ｜ 依赖：T0；联调 T1（ui_request 帧）、T4（事件总线） ｜ 被依赖：T7（respondDialog/rules handler）、T8（对话框与设置 UI）
> 方案依据：方案第 4 章
> 职责边界：权限判定、拦截、规则热读、超时默认拒绝全部在 hub；**Pai 只做 UI 交互并把操作经协议提交**（ui_response / rules 命令 / trusted 参数），不写规则文件、不镜像判定逻辑。

## 契约

```typescript
// packages/approval —— 只依赖 contracts
onUiRequest(frame: UiRequestFrame): void        // 产生 dialog_request UiEvent；挂起表登记 {requestId, method, deadline}
respondDialog(requestId, payload): Promise<'settled'|'expired'>
// payload 形态随 method：confirm→{confirmed} | select→{value} | input→{value} | editor→{value|cancelled}
// notify/setStatus：单向事件，UI 展示即可，无需回包
// 超时兜底在 hub；桥侧只透传 deadline 供 UI 倒计时与超时结果展示
trusted：requestTrustedApproval(projectPath) → 视图态记录 + thread/start 参数组装（提交给 hub 执行）
rules：经协议透传（rules 读/写命令由 hub 提供）：listRules() / submitRules(next) → 包装为命令 + response 透传
```

- 时序：dialog_request 恰好一次；respondDialog 对未知/已结算 id 返回 expired（hub 已 ack，不报错）；渲染层刷新后经 `getStateSnapshot` 的挂起对话框列表重水化。
- 错误形态：全部中性英文 reason；桥内任何失败不阻断事件流。

## 问题域

- 处理：ui_request 全方法族（confirm/select/input/editor/notify/setStatus）桥接与挂起表；trusted 逐项目审批的视图态与参数提交；rules 命令的协议透传层（无本地判定副本，设置页可做纯展示性匹配预览并标注「以 hub 判定为准」）；超时倒计时同步。
- 不处理：权限判定与规则存储（hub）；hub 侧 rules 命令的实现（外部依赖，未就绪时设置页降级只读）；对话框渲染（T8）；auth 交互（API key 设置，T8 直连命令）。

## 并发/一致性预算

- 挂起对话框数 ≤ 活跃 thread 数（≤8）；桥不设本地超时定时器（deadline 单一真相在 hub）；回调禁 IO。

## 实施顺序（每步独立测试 + 四门全绿后提交）

| # | 内容 | 单测 | 验收 |
| --- | --- | --- | --- |
| M1 | DialogBridge 状态机 | 表驱动：六方法 × 请求/回包两侧；重复 respond→expired；晚到忽略；刷新重水化快照合并 | 状态机全覆盖 |
| M2 | trusted 审批 | 逐项目审批/记忆/重置语义；默认 false；参数组装断言（thread/start 含 trusted:true 仅在已审批后） | 与 T4 联动 |

| M4 | 超时协同 | deadline 过期展示/回包竞态（过期后到达→expired） | 与 hub 默认拒绝语义一致 |

## 裁决

- 桥不设本地超时定时器，只透传 hub deadline：既有裁决（单一真相在 hub）。
- rules 交互为纯协议透传、无本地判定副本：用户裁决（Pai 只做 UI 交互）。

## 测试口径

- 契约断言：dialog_request 恰好一次；respondDialog 三结果穷举；六方法 payload 形态穷举；rules 透传无本地加工（请求/响应保真级断言）。
- 边界/竞态：超时后回包；同 requestId 双击；thread 停止时挂起对话框清理（hub 侧 settle，桥状态同步）；坏 payload 形状；rules 命令缺失降级。
- 分层：单元（状态机表驱动）+ integration（真 hub 权限门往返，T9 夜间门）。
