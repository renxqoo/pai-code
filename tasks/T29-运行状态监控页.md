## 用户裁决（2026-09-10 确认）

1. **完整形态一步到位**，不分阶段；hub + Pai 两仓一起改。
2. **常驻开关纳入**：按会话声明不自动回收（监控表 📌 标记 + 侧栏可切换）。
3. **强制回收纳入**：执行中会话一键 停止生成+清队列+回收（溢出菜单，主按钮仍为「停止」）。
4. **回收档位 3/5/10/15 分钟，默认 5**（「启动非常快」——唤醒成本低，激进回收可接受）；不设「从不」档（常驻覆盖该需求）。
5. UI 由 ui agent 实现：只传功能/背景/数据契约，布局不设限；数据逻辑全在主会话。

## 契约

### hub 协议 v0.13 增量（外部仓库先行，docs/design.md §契约 v0.13）

- **命令 `thread/retire`** `{threadId}`：手动触发闲置回收同型路径（retireIntent='retire'，stdin.end + 有界强杀），close 时表项转 parked。幂等：未知/非 live 线程直接 ack success（与 thread/stop 对齐）。streaming 线程允许 retire（在途命令由 close 对账合成失败——既有终态契约）。
- **命令 `thread/set_keepalive`** `{threadId, keepalive}`：host 本地（零 worker），置表项 keepalive 标志；未知线程 failure。sweep 对 keepalive 表项跳过闲置回收。
- **命令 `set_idle_retire_ms`** `{ms}`：host 本地，运行期调整闲置阈值（钳制 1..86_400_000），响应回实际生效值；`get_host_info.limits.idleRetireMs` 同步反映。免重启改档位。
- **`thread/list` 行扩展**：`idleMs`(live=worker 心跳值，非 live=0)、`subagents`(live 聚合，非 live=0)、`rssBytes`(worker 心跳上报，未上报=null)、`keepalive`。
- **帧 `thread_parked`** `{threadId, reason: 'idle'|'manual'}`：settleClosedWorker 的 retire 分支发射（与 thread_died 同层）；stop/shutdown 不发。
- **宿主心跳帧扩展**：`rssBytes?`/`cpuPercent?`（process.cpuUsage 1s 差分，单核归一可>100；条件展开）。
- **worker 心跳帧扩展**（host↔worker 内部）：恒带 `rssBytes`；WorkerHandle 折叠 rssBytes。
- 既有 `get_host_info` 零改动直接消费（版本/pid/uptime/RSS/线程计数/子代理/limits/backend）。

### 本仓库 contracts（镜像同步 + 命令面）

- `hub-protocol.ts`：上述命令/帧/字段的镜像抄录 + 词表（HUB_COMMAND_TYPES 40→43、HUB_FRAME_TYPES 8→9）。
- `commands.ts`：`PaiCommandType` += `get_host_info`、`thread/list`、`thread/retire`、`thread/set_keepalive`、`set_idle_retire_ms`。
- `ui-events.ts`：UiEvent += `sessionParked {threadId, reason:'idle'|'manual'}`（worker 回收推送；渲染层与主进程折叠 parked 态）。

### 本仓库 API 面（packages/contracts/src/api.ts）

- 新增视图：`HostInfoView`（get_host_info 收窄）、`WorkerRowView`（thread/list 行收窄）、`ResourceSampleView`（at/appRss/appCpu/hubRss/hubCpu/workersRss/systemAvailable/systemTotal）、`RuntimeEventView`（at/level/kind/detail）、`RuntimeSnapshotView`（hostPhase/hostInfo/heartbeatAgeMs/restarts/workers/latest/history(降采样≤180点)/events(≤50)/idleRecycleMinutes/appVersion）。
- 新增方法：
  - `app/runtime` {} → RuntimeSnapshotView（监控页 2s 轮询；不含 stderr——带宽纪律）
  - `app/diagnosticLog` {} → {stderrTail}（按需）
  - `app/setIdleRecycle` {minutes: 3|5|10|15} → {minutes}（落 settings + set_idle_retire_ms，单一写路径）
  - `app/exportDiagnostics` {} → {directory}（userData/diagnostics/<ts>/ 目录：summary.md + 日志副本 + stderr + 快照，Finder 定位；不引 zip 依赖）
  - `session/retire` {threadId} → null（空闲回收；thread/retire）
  - `session/forceRetire` {threadId} → null（clear_queue + abort + thread/retire，逐条容错）
  - `session/setKeepalive` {threadId, keepalive} → null（registry 持久 + hub 置位；parked 未纳管先 register）
- **删除 `app/diagnostics`**（hostPhase/stderrTail/registrySessions 并入 app/runtime + app/diagnosticLog；零双轨）。
- `PreferencesViewSchema` += `idleRecycleMinutes: 3|5|10|15`。

### 持久化与真相链

- **闲置档位**：settings.json `idleRecycleMinutes`（真相）→ spawn env `PAI_IDLE_RETIRE_MS` 注入（重启一致性）+ 运行期 `set_idle_retire_ms`（即时生效）。
- **常驻**：registry `sessions.keepalive` 列（真相，ALTER TABLE 迁移，默认 0）→ 会话 live 化（start/resume/register 成功）且行 keepalive=1 时 re-assert `thread/set_keepalive`；hub 表项标志为运行期镜像（hub 重启后由 re-assert 重建）。
- **worker 表**：hub `thread/list` 为进程态真相 × registry/store（标题/stats/排队）join；2s 轮询顺带做状态漂移纠正（hub 说 parked 而内存视图 live → 折叠）。

## 问题域

- 处理：hub v0.13 全量（外部仓库）；contracts/adapter 镜像与解码；主进程运行时监控（2s 采样器：app metrics/os/hub 轮询 + 心跳资源折叠 + 30min 环 + 监督事件环 + 重启计数）；HostProcessPort.diagnostics() 扩展（restartCount/lastRestartCause/lastRestartAt）；create-host-process 心跳帧透传（onFrame 收到 heartbeat，主进程只折叠不推 UiEvent）；registry keepalive 列与 re-assert；api 路由全量；渲染层数据层（use-runtime-panel/store sessionParked 折叠/actions/controller）；设置改造（移除 diagnostics 分区、常规区加回收档位）；监控页 UI + 图表组件（ui agent）；侧栏入口 + 异常徽标 + 会话行「回收」hover 动作；strings 全量。
- 不处理：
  - 全系统进程监控（Activity Monitor 职责；本页只看本应用足迹 + 系统内存上下文）；
  - 资源历史持久化（30min 内存环，重启清零——监控不是舰队观测）；
  - **per-worker CPU**（RSS 是资源主相；CPU 采样噪声大价值低——默认裁决，否决窗口）；
  - 子代理个体展开（只显示在途计数）；
  - token 趋势/日预算（用量页与 T4 职责；本页只带每会话现有 stats 快照）；
  - 「从不」回收档（用户裁决 4：常驻覆盖）;
  - worker 级排队深度下发（thread/list 无此字段；表格排队列取渲染层 store 队列镜像）；
  - hub 侧 keepalive 持久化（registry 是唯一持久真相，hub 内存态）；
  - stderr 实时流（保持 64KB 环 + 按需拉取）。

## 并发/一致性预算

- 主进程监控：**1 个 setInterval（2s）**；每 tick ≤2 个 hub 命令（thread/list + get_host_info，均 host 本地零 worker 唤醒）+ 1 次 appMetrics + 1 次 os 读取；环上限 900 样本（30min）× ≤200B。
- 监督事件环 ≤200 条；快照 events 裁 50、history 降采样 ≤180 点（单次 IPC ≤ ~40KB）。
- 心跳折叠：1Hz 帧进 dispatchFrame，仅更新内存计数，零 UiEvent、零 IPC。
- 渲染层轮询：监控页打开时 1 个 interval（2s）invoke `app/runtime`；关闭即清（use-session-ages 同型）。
- 回收三命令幂等；失败不自动重试（notice 提示，用户重试）。
- keepalive re-assert：每会话 live 化至多 1 次 void 调用，失败静默（下次 live 化再试）。
